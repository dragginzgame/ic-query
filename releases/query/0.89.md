# Query 0.89 release notes

## 0.89.0

### ⚠️ Breaking

Registry archive/delta replay is retired. The library no longer collects certified
change batches, bootstraps, extends, restores or cleans archives, reconstructs
Registry state, or projects and caches archive-backed certified catalogs. Remove
`certified-subnet-catalog-host` from feature selections. The existing
`nns-host` feature retains authenticated latest-version reports and ordinary
NNS queries; `subnet-catalog-host` and `nns-topology-host` retain their focused
ordinary query/cache surfaces.

Catalog assurance now describes single-endpoint ordinary queries or explicit
multi-endpoint agreement. The certified assurance variant, archive commitment
record and `SubnetCatalogProvenance.certified_registry` field are removed.
Ordinary catalog provenance remains strict: earlier files containing the removed
field are not accepted, even when its value was null. Catalog and related contract
schema identifiers remain 1, and canonical catalog digests change with the shape.

Complete NNS/SNS Governance and ICRC account-history refreshes, Subnet Catalog
list/detail builders and the CloudEngine list builder retain a live convenience
function plus their full custom-source/progress function. Callers of the removed
source-only or progress-only permutations must pass both dependencies explicitly.
Use the corresponding live source for standard transport and a no-op closure when
progress is unwanted. CloudEngine accepts its Registry and control-plane sources.
Source traits, typed progress and caller-owned runtimes remain the boundaries.

### 🧭 Migration Notes

Preserve existing archive objects, manifests, commitments and any catalog cache
needed as historical evidence, together with the version of Query that can inspect
them. This release does not delete, rewrite or migrate caller files. Retire archive
capture roots from current consumers rather than treating historical evidence as
an ordinary catalog. Coordinate consumers of the removed Rust and JSON contracts.
For an ordinary catalog, preserve the former snapshot before explicitly refreshing
under the current cache policy. No compatibility reader or automatic migration is
provided.

The certified latest-version report still verifies the certificate, witness and
committed version leaf. It does not certify ordinary Registry values. Ordinary
Registry history transcripts, bounded hash-verified value chunk reconstruction,
endpoint agreement, confinement, refresh locking and failed-publication evidence
remain in place.

### 🧹 Cleanup

Remove the retired capability's transport, authentication/replay, archive storage
and cleanup machinery, projections and fixtures. Remove duplicate cached inventory
integration scenarios while keeping owner-level cache behavior and external source
trait, continuation and rendering coverage. Retain Governance smoke and compiled
canister/Testkit checks, which cover separate execution boundaries.

### ⚠️ Additional 0.89 contract cuts

Retire SNS reward checkpoint collection, portable validation/diffing, file loading,
source/wire adapters and their report models. The CLI/Text group removes the
`icq sns reward` namespace and checkpoint/diff renderers. Preserve historical
checkpoint files with the former tooling needed to inspect them; current Query
has no reader or migration and does not delete caller files. Ordinary SNS neuron,
parameter, proposal, metrics, swap and upgrade queries remain available.

Remove independently stored returned-array counts from NNS inventories, IC
Dashboard pages/observations, SNS lists, canister/gap and treasury metrics, and
selected topology lists. Use retained arrays for counts. Independent source totals,
full-snapshot sizes and operational acquisition evidence remain. Text derives the
same human-facing counts. Current report JSON and affected inventory-cache shapes
omit the duplicate fields; preserve old evidence and explicitly refresh caches.
All schema identifiers stay 1, without a compatibility reader or migration.

Remove formatted topology utilization, join-coverage and check-detail fields from
Core reports and its percentage-text exports. Numeric evidence and typed statuses
remain authoritative; Text derives the existing human-facing percentages and
check details with the same rounding and unavailable-value rules.

### 🧪 Testing

Retire SNS reward-only fixtures and scenarios with the capability. Consolidate
remaining repeated SNS/IC collection checks in owner tests while preserving public
interface, rendering, source rejection and cache recovery coverage. Remove stale
Core rendering-test remnants; percentage formatting boundaries now belong to Text.

### 🔧 Dependency and tooling alignment

Adopt published Platform/PocketIC/Runtime 0.19.0 and canonical Types 0.18.0,
Host Tools 0.79.0, Foundation 0.74.2, Build 0.74.1, Testkit 0.81.0 and Wire 0.16.0.
Host Text remains 0.74.1. Shared Tooling selects committed source 0.28.0 at
`70939d3`; its supplier ledger is still Unreleased. Rust remains pinned at 1.99.1.

The simulator fixture admits typed client rejection errors and explicitly checks
fallible time, funding and installation operations. Query's owned probe uses Wire
for primitive string frames; it does not select Wire's Account schemas. Production
graphs remain Wire-free and share one Platform/Types/Runtime family. Native host,
installed server, certificate, dependency-boundary and release checks remain required;
release-group validation narrowing is not activated by snapshot adoption.
