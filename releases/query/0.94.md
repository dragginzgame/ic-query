# Query 0.94 release notes

## 0.94.0

### ⚠️ Platform 0.24 adoption

Select published Platform 0.24.0 in the root dependency catalog and lockfile.
Query already uses bounded Candid decoding and does not use the removed offline
secp256k1 derivation capability, so neither upstream removal needs a local shim.

Query’s public `CertificateVerificationError::Decode` now contains Platform
0.24’s `certification::cbor::strict::ParseError`. Rust consumers that construct,
match or downcast that source must align their Platform dependency on 0.24.
This public type-identity change requires a Query minor release. CLI commands,
report JSON, schema-1 contracts, response bounds and text output are unchanged.

Published Host Tools 0.84.0 and Testkit 0.90.0 still require Platform 0.23, so
their transitive 0.23.6 facade remains alongside Query’s 0.24.0 selection. Agent,
Candid and canonical Principal types retain their shared supplier identities.
Select the existing Wire 0.17.7 lockfile update for owned application RPCs.

The Agent path still reaches affected crypto-bigint 0.5.5. This adoption does not
resolve RUSTSEC-2026-0387 or extend the existing acceptance deadline; the gate
continues refusing from 21 November UTC.

### ⬆️ Build and Host updates

Select Build 0.78.0 and Host Artifacts, FS, HTTP and Process 0.75.0. Query
does not use the retired compiler wrapper, cross-call prepared snapshots,
source leases, output progress variants or Process provenance/RSS helpers.
Its Governance build retains fresh input resolution and post-build revalidation,
bounded process evidence, exact source fingerprints and atomic output writes.
Cache confinement, private writes/locks and bounded HTTP body reads retain
their existing owners and policies.

Adopt Host Tools 0.84.0, aligning its artifact, filesystem and process
dependencies with Foundation 0.75. Host Text stays on 0.74.2. Testkit 0.90.0
still requires Foundation 0.74, which remains transitively alongside the
0.75 selection. No compatibility alias or sibling override is added.

### 🩹 Shared release-checker repair

Adopt Shared Tooling 0.31.5 at `b2026a1`. Its release-command checker
clears inherited batch settings, substitutes both runners and verifies
outer grouped dispatch and captured inner dispatch separately. Keep failure
propagation and fixture evidence intact; use portable manifest edits in
the supplying regression fixtures. The exporter retains the release-batch
guide as a required companion of documents that link to it. Query’s frozen
delivery, supplier-first publication and schema-1 product contracts remain.

Query’s frozen-batch fixture selects detail-note ownership from its simulated
patch version, rather than inheriting the real pending minor’s file. Keep the
real minor release’s policy unchanged and retain interruption, deferred-input,
publication-receipt and reconciliation assertions.
