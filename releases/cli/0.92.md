# CLI and Text 0.92 release notes

## 0.92.0 - 2026-11-05

### ⬆️ Platform alignment

Select Platform 0.23.0 directly through the workspace catalog. Query has no
caller of its changed optional subnet-metrics decoder. Host Tools and Testkit
still select Platform 0.22; preserve those published requirements while keeping
canonical Types and Runtime shared. Native packet fixtures remain development
only and report JSON is unchanged.

### ⬆️ Development protocol alignment

Adopt Testkit 0.86.0 and Wire 0.17.2 together for the compiled Governance
probe, native simulator fixture and smoke harness. Testkit now selects the
same Wire minor line as those callers. The owned endpoints use Serde directly,
so Wire’s optional schema derive leaves this lockfile. Existing frame bytes,
method identities, decode budgets and malformed/trailing-frame rejection remain
the protocol contract. Report JSON remains at schema 1.

### ⚠️ Query model codec boundary

The public text renderers consume Query 0.92's report models, whose owned
values no longer implement Candid codec traits. Adopt the corresponding Query
model generation when calling those Rust renderers. CLI JSON, text formatting
and external IC protocol bytes are unchanged. See [Query's migration](../query/0.92.md)
and [#114](https://github.com/dragginzgame/ic-query/issues/114).
