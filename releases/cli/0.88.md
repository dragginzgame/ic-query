# CLI and Text 0.88 release notes

## 0.88.0 - 2026-11-02

### ⚠️ Breaking

Adopt the [Query 0.88 consumer contracts](../query/0.88.md). SNS reward checkpoint
JSON now retains raw evidence without independently stored summaries, counters or
formatted timestamps. Preserve historical checkpoint files and coordinate script
consumers before adopting the strict current schema-1 shape. Readers never migrate
or rewrite former files, and new collection does not replace historical evidence.

Text derives the same valid checkpoint summary from raw evidence with checked
arithmetic. An unrepresentable raw maturity total produces a bounded diagnostic.
CLI inventory advice uses the shared typed collection identity.

Adopt Query's raw SNS permission codes, derived exact-neuron policy observations
and removal of redundant report counts. JSON consumers obtain returned counts
from arrays; independent total counts remain. ICRC stored snapshots omit duplicate
transaction bounds, while list/refresh/status output retains complete-snapshot
bounds. Preserve affected caches and historical reports before coordinating the
schema-1 hard cut described in the Query notes. Human-facing counts, permission
names and policy labels are derived by Text.

Adopt Query's raw node-status snapshots, provider-count-only Subnet topology and
raw Registry reports. Text derives the same valid topology counts and Registry
certificate time/length labels. Registry JSON carries raw summary inputs; Rust
consumers use the checked summary API. Preserve earlier certified archives and their
original manifests/object hashes, coordinate consumers and select a new capture
root under the Query notes; the CLI does not convert historical evidence.

### 🧹 Cleanup

ICRC account balance, allowance and transaction-history commands declare arguments
and extract requests through the same typed Clap records. Native ledger and
analytics endpoints remain explicit. Existing commands, flags, defaults, argument
normalization, page bounds, namespace help and collection/network policies remain
unchanged. This batch adds no CLI surface.

Release and publish Query before this group.
