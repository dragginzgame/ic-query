# CLI and Text 0.95 release notes

## 0.95.0 - 2026-11-07

### ⚠️ Host Tools type alignment

Select Host Tools 0.85.0. Query’s public `certificate::authenticate_ledger_tip`
now returns `ic_host_tools::ledger_evidence::LedgerTip` from that version.
Consumers passing the returned tip to Host’s chain verifier must select Host
Tools 0.85 too. The fields, certificate admission and chain-verification policy
retain their behavior, but the public Rust type identity requires a Query minor.

### ⬆️ Testkit and shared supplier graph

Adopt Testkit 0.92.0, including its Foundation 0.75 execution/cleanup errors and
Platform 0.24 `CborError` identity. Keep the fixture’s five-minute request budget,
separate one-minute startup deadline, typed external protocols, NNS/application
topology, provenance/failure assertions and awaited explicit close.

Both suppliers now share Query’s Platform 0.24 and Foundation 0.75 selections.
Remove the older Platform 0.23.6 and Host Artifacts/FS/Process 0.74.4 copies.
Canonical Types 0.18.2, Runtime 0.19.5 and management DTO 0.11.0 remain aligned.
Select Wire 0.17.10; its published codec bytes,
identities and limits are unchanged. Build 0.78.0 and Shared Tooling 0.31.5 remain.

Report and cache schemas stay at 1. Commands, text/JSON output, response quotas
and endpoint policy remain unchanged. The Agent crypto dependency still reaches
RUSTSEC-2026-0387; its existing acceptance deadline is not extended.
