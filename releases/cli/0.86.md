# CLI and text presentation 0.86 notes

## 0.86.0

### ⚠️ Breaking

`ic-query-text` owns pure report-to-string presentation under command-family
namespaces. Import DTOs and builders from `ic_query`, and renderers from
`ic_query_text`. The CLI consumes both; no library-to-presentation dependency or
compatibility re-export is retained. JSON serialization stays with Query's typed
reports and keeps the extraction independent of data contracts. Existing text,
escaping, provenance sections, amount rounding and terminal responsibilities are
preserved. Query 0.86's earlier model changes have their own
[consumer actions](../query/0.86.md).

The `query` group contains the library and private Testkit; the `cli` group
contains the CLI and text package. All members retain their current numeric
baseline as explicit package versions. Both groups currently have pending 0.86
changes; publish Query's required data contract before the CLI/text consumer.
Future CLI-only presentation, flags or installation changes can release without
republishing Query. Keep a compatible dependency requirement on the library.

Use the existing release and publication commands with explicit
`RELEASE_GROUP=query` or `RELEASE_GROUP=cli`. Missing or unknown selections refuse
before setup or mutation. Each group owns its ledger and metadata transaction;
previous coordinated history remains in [shared history](../history.md). Full
repository CI and all native hosts remain required; group selection does not
activate a narrower validation plan. No release, tag or publication is executed
by adopting these boundaries.

Metadata fixtures select their own synthetic detailed-notes paths for the next
candidate. They continue to qualify both groups after either advances, without
changing the real group's reviewed policy or finalized notes.

The smoke harness and development fixtures adopt Testkit 0.80, retaining its
private Metrics 0.26 selection. Query owns report arithmetic without Metrics.
They use published
Wire 0.15.0 through
the shared catalog. Its codec bytes and budgets are unchanged, and its Rust
1.99.1 minimum matches Query's existing compiler. Wire remains outside the
production CLI and reusable library graphs.

Complete or explicitly reconcile any outstanding unqualified release attempt
using its retained source and tooling before grouped delivery. Preserve its
journals and tags; the grouped runner does not reinterpret older attempt state.

Select the group explicitly for version inspection:

```bash
make version RELEASE_GROUP=cli
```
