# CLI and Text 0.87 release notes

## 0.87.0

### ⚠️ Breaking

Adopt the [Query 0.87 report and request contracts](../query/0.87.md). Existing
CLI commands and flags remain available. JSON no longer carries presentation
flags, independently stored SNS proposal lifecycle/ballot counts, or NNS neuron
`from_cache`; cache summaries and ICRC account identities use explicit outcomes.
Coordinate script consumers and preserve required historical evidence before
refreshing changed schema-1 SNS proposal and ICRC account-history snapshots.

Reusable renderers take `ic_query_text::TextOptions` for SNS lists, proposal lists
and details, neuron lists, and NNS proposal lists/details and neuron lists. Pass
the same options separately to SNS metadata styling. The CLI forwards its existing
`--verbose` and `--ballots` choices directly to Text, leaving report collection and
JSON independent of display choices. Ballots remain in raw report data regardless
of whether text displays them. Compact and expanded report text retain their
existing behavior; invalid-cache output omits invented collection metadata.

### 🧹 Cleanup

Paged progress formatting has one CLI owner. Collectors send typed collection
identity, admitted counts, target and lifecycle state. Existing progress wording,
including account-history completion behavior, is preserved, and target names
are escaped before terminal output. Typed Governance collection identities
replace string fallbacks when constructing refresh hints.

No new CLI surface, endpoint default, cache identity or live-call policy is added.
Release and publish Query before this group.
