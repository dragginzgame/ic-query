# CLI and Text 0.89 release notes

## 0.89.0

### ⚠️ Breaking

Adopt the [Query 0.89 consumer contracts](../query/0.89.md): Registry archive/replay
and archive-backed certified catalog APIs are retired, and ordinary catalog
provenance loses its archive-only field. Preserve historical files and their earlier
reader before coordinating the strict schema-1 cut. Consumers must explicitly
refresh ordinary catalogs after preserving evidence. The CLI's Registry version
command and ordinary inventory/topology commands remain available.

CLI collection dispatch supplies live sources to Query's canonical source/progress
entry points. Rust consumers of the removed forwarding variants must similarly
provide both source and progress dependencies. No commands, options or output
formats are added.

### 🧹 Cleanup

Use Host Text 0.74.1 for integer quantity scaling, exact two-place rounding and
rounded-boundary unit promotion. Query retains decimal cycle and binary byte unit
selection, raw decimal admission and fallback evidence. This formatting delegation leaves text and JSON output
unchanged; it adds no commands or flags.

Consolidate repeated binary help scaffolding without removing command paths or
assertions. Retire duplicated cached inventory behavior from the Text public API
suite; owner tests retain that behavior, while public source-trait execution,
continuation contracts and exact renderer fixtures remain.

### 🗑️ Removed

Remove `icq sns reward checkpoint` and `icq sns reward diff`, their options,
local-only network-selection branch and Text renderers. Historical checkpoint
files remain untouched; retain the earlier tooling for inspection.

### ⚠️ Further consumer updates

Adopt Query's remaining returned-count removals and numeric topology contracts.
Text computes counts, utilization percentages and consistency-check details from
raw evidence while preserving the existing output for retained commands. Report
JSON and affected inventory caches use the strict replacement shape at schema 1;
preserve historical evidence before explicitly refreshing. Core's percentage-text
helpers are retired. Repeated SNS/IC host-behavior tests now stay with their Core
owners, with external-interface and renderer checks retained in Text.

### 🔧 Dependency and tooling alignment

Adopt published Platform/PocketIC/Runtime 0.19.0 and canonical Types 0.18.0,
Host Tools 0.79.0, Foundation 0.74.2, Build 0.74.1, Testkit 0.81.0 and Wire 0.16.0.
Host Text remains 0.74.1. Shared Tooling selects committed source 0.28.0 at
`70939d3`; its supplier ledger is still Unreleased. Rust remains pinned at 1.99.1.

The simulator fixture admits typed client rejection errors and explicitly checks
fallible time, funding and installation operations. Query's owned probe uses Wire
for primitive string frames; it does not select Wire's Account schemas. Production
graphs remain Wire-free and share one Platform/Types/Runtime family. Native host,
installed server, certificate, dependency-boundary and release checks remain required;
release-group validation narrowing is not activated by snapshot adoption.
