# 0.55 release notes

## 0.55.6

- Canonically adopts Shared Tooling 0.11.4 at
  `031d214ed044705b989d43e2379f30e6a3d44749`, selecting its fixture lifecycle
  and pure workspace-version renderer. Common tool pins remain unchanged.
- Nine consumer fixture owners share completion admission, original failure
  status, successful cleanup and failed-evidence retention. Created directories
  are physically anchored before trap registration with `CDPATH` cleared.
  Actual caller traps cover nounset, partial completion, cleanup/reporting
  refusal and retargeted relative temporary roots without discarding evidence.
  [#49](https://github.com/dragginzgame/ic-query/issues/49).
- Workspace-version candidates are rendered from an owned copy of authenticated
  saved-source bytes. Query retains its owned dependency substitution, four-file
  roster, detailed notes, exact working/index/commit admission and manifest-last
  reconciliation. Mixed before/prepared files are reconciled deterministically;
  altered retained inputs are refused before metadata publication.
  [#50](https://github.com/dragginzgame/ic-query/issues/50).

## 0.55.5 - 2026-10-13

- Canonically adopts Shared Tooling 0.11.0 at
  `a15ff323449f4b6190f647aec0de43cbcfb314ba`, retaining 81 roots and 91
  payloads. CI inspection refuses malformed run IDs and conflicting selectors
  before observations; host/IC installers use shared managed-pointer admission.
  Full tool pin records and existing installation/build identities are unchanged.
  Query has no callers or selected roots for the removed CI installer wrappers.
  The optional Cargo release-metadata helper and unpublished fixture-lifecycle
  draft are not selected; current Query adapters retain their own contracts.
  Restores committed manifest/module ordering required by the format gate,
  preserving dependency values, feature conditions and package versions.

- Expose opt-in bounded certificate/witness and ICRC-3 tip authentication with
  typed failures and caller-selected budgets. Share witness commitment checks
  with existing certified reports; callers retain trust-root and payment policy.
- Expose opt-in bounded generic ledger-block admission and contiguous chain
  verification. Admitted immutable values cannot change before hashing; ledger
  transaction interpretation and spending authority remain consumer-owned.
  Documents certificate and block budgets, authenticated tip fields and typed refusals.

- All NNS topology read commands use the existing NNS common options and one
  concrete request-construction path. Command-specific report builders remain
  separate; endpoint, network, output defaults, cache root and observation time
  are preserved. No public library API or CLI surface changes.
- SNS runners consume their parsed options directly instead of repacking them
  into intermediate runtime records. Clock selection remains before cache-root
  resolution for lookup commands; cache inspection stays clock-free, and neuron
  list cache selection still depends on the requested sort. Report requests,
  error precedence and command output are preserved.
- NNS inventory runners construct cache requests directly and retain cache-root
  resolution before clock selection. SNS catalog refresh reuses shared
  endpoint/output parsing and the dispatch-selected network, preserving refresh
  progress, lock defaults, request identity and command syntax.
- NNS/SNS clock selection and ICRC endpoint/output parsing use their common
  owners directly. SNS caches use the shared snapshot-path representation while
  retaining typed collection selection for refresh and publication. Error order,
  cache-only behavior, public paths and stored identities are preserved.
  [#51](https://github.com/dragginzgame/ic-query/issues/51).

## 0.55.0 - 2026-10-12

- Scopes Tokio's test networking feature to native targets, preserving Wasm
  Governance probe builds. Runtime dependency checks omit development-only
  edges; canister API probes construct and drop caller-owned futures without
  polling live calls. Pure/canister production graphs remain transport-free.
  Cache helper exports follow their Registry owners so individual Dashboard,
  ICRC and SNS features compile without activating Registry dependencies.
- Release metadata admission no longer requires old-version dependency snippets
  in README/library usage or rewrites and stages those documents. Reviewed
  examples remain unchanged, including already-selected versions, valid ranges
  and prose without snippets. Source cleanliness, Cargo/lockfile identity and
  selected changelog preparation remain required. README freshness follows the
  shared advisory task. [Shared #100](https://github.com/dragginzgame/shared-tooling/issues/100).
- **Breaking:** host source capabilities, live collection and read-through
  builders return caller-runtime futures. Await native operations and retain
  synchronous pure projections, renderers and explicit cache-only readers.
  Library runtime creation, nested-runtime helper threads and their runtime
  error variants are removed. Catalog load/refresh operations keep one canonical
  async spelling rather than paired blocking/async entrypoints.
- Object-safe host capabilities require `Sync` and return the shared boxed
  `Send` source future. Progress sinks require `Send`; portable Governance
  source/provenance futures keep their own authority contracts. CLI library
  dispatch is async, and the executable owns one current-thread Tokio runtime
  per command, retaining help, exit-code, broken-pipe and output behavior.
- Stateful CloudEngine, ICRC, NNS Governance and SNS adapters reuse an agent
  bound to the first admitted endpoint and response ceiling. Construct adapters
  with `::default()` and create another source for another endpoint. Dashboard
  adapters reuse their bounded HTTP client. Family network/root-key policy,
  response limits, deadlines and typed reply evidence remain in their owners.
- Awaited refresh work retains its filesystem lock and attempt lifecycle;
  cancellation releases the owned lock without publishing an incomplete
  snapshot. Complete cache identity, previous snapshots, retained attempt
  evidence, schema-1 JSON and pure/canister dependency boundaries are preserved.
  [Library usage](../library-usage.md) documents the replacement contracts.
- Canonically adopts Shared Tooling 0.9.5 at
  `b1630b89482cc6071fc928a86962d79c9c11fdb7`, retaining 82 roots/89 payloads.
  Host/IC setup shares lock cleanup and preserves original installation failures
  when cleanup also fails. Installers reject supplied/resolved CR/LF consumer
  paths; evidence checks reject NUL before hashing. Explicit asset setup retries
  transient transport failures with bounded attempts/time, preserving terminal
  checksum failures and retained candidates. Snapshot/release recovery accepts
  complete 40- or 64-character Git identities. The optional producer artifact
  discovery helper is outside Query's selected payload set.
  [Shared #138](https://github.com/dragginzgame/shared-tooling/issues/138),
  [#133](https://github.com/dragginzgame/shared-tooling/issues/133).
- Preserves the selected Host artifacts/filesystem/process 0.15.1 update.
  Native tooling acceptance remains under
  [Query #44](https://github.com/dragginzgame/ic-query/issues/44).
