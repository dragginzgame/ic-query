# 0.55 release notes

## 0.55.0

- Scopes Tokio's test networking feature to native targets, preserving Wasm
  Governance probe builds. Runtime dependency checks omit development-only
  edges; canister API probes construct and drop caller-owned futures without
  polling live calls. Pure/canister production graphs remain transport-free.
  Cache helper exports follow their Registry owners so individual Dashboard,
  ICRC and SNS features compile without activating Registry dependencies.
- Release metadata admission no longer requires old-version dependency snippets
  in README/library usage or rewrites and stages those documents. Reviewed
  examples remain unchanged, including already-selected versions, valid ranges
  and prose without snippets. Source cleanliness, Cargo/lockfile identity and
  selected changelog preparation remain required. README freshness follows the
  shared advisory task. [Shared #100](https://github.com/dragginzgame/shared-tooling/issues/100).
- **Breaking:** host source capabilities, live collection and read-through
  builders return caller-runtime futures. Await native operations and retain
  synchronous pure projections, renderers and explicit cache-only readers.
  Library runtime creation, nested-runtime helper threads and their runtime
  error variants are removed. Catalog load/refresh operations keep one canonical
  async spelling rather than paired blocking/async entrypoints.
- Object-safe host capabilities require `Sync` and return the shared boxed
  `Send` source future. Progress sinks require `Send`; portable Governance
  source/provenance futures keep their own authority contracts. CLI library
  dispatch is async, and the executable owns one current-thread Tokio runtime
  per command, retaining help, exit-code, broken-pipe and output behavior.
- Stateful CloudEngine, ICRC, NNS Governance and SNS adapters reuse an agent
  bound to the first admitted endpoint and response ceiling. Construct adapters
  with `::default()` and create another source for another endpoint. Dashboard
  adapters reuse their bounded HTTP client. Family network/root-key policy,
  response limits, deadlines and typed reply evidence remain in their owners.
- Awaited refresh work retains its filesystem lock and attempt lifecycle;
  cancellation releases the owned lock without publishing an incomplete
  snapshot. Complete cache identity, previous snapshots, retained attempt
  evidence, schema-1 JSON and pure/canister dependency boundaries are preserved.
  [Library usage](../library-usage.md) documents the replacement contracts.
- Canonically adopts Shared Tooling 0.9.5 at
  `b1630b89482cc6071fc928a86962d79c9c11fdb7`, retaining 82 roots/89 payloads.
  Host/IC setup shares lock cleanup and preserves original installation failures
  when cleanup also fails. Installers reject supplied/resolved CR/LF consumer
  paths; evidence checks reject NUL before hashing. Explicit asset setup retries
  transient transport failures with bounded attempts/time, preserving terminal
  checksum failures and retained candidates. Snapshot/release recovery accepts
  complete 40- or 64-character Git identities. The optional producer artifact
  discovery helper is outside Query's selected payload set.
  [Shared #138](https://github.com/dragginzgame/shared-tooling/issues/138),
  [#133](https://github.com/dragginzgame/shared-tooling/issues/133).
- Preserves the selected Host artifacts/filesystem/process 0.15.1 update.
  Native tooling acceptance remains under
  [Query #44](https://github.com/dragginzgame/ic-query/issues/44).
