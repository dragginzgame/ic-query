# 0.52 release notes

## 0.52.0

- Hard-cuts the common IC tool bundle to Quill, ICP CLI, didc, ic-wasm and
  wasm-opt through reviewed Shared Tooling 0.2.0 at
  `8140e3dd1b44409d682c721889ab702f438c6a17`. PocketIC provisioning, pins and
  installer branches are removed together. The 73-file snapshot selection and
  separately pinned engineering baseline remain intact; retired PocketIC
  checkers were never selected in Query.
  [#33](https://github.com/dragginzgame/ic-query/issues/33),
  [Shared #76](https://github.com/dragginzgame/shared-tooling/issues/76).
- Existing six-tool bundles fail the new offline check. Run explicit
  `make install-ic-tools` to activate the five-tool bundle, then
  `make ic-tools-check`. Prior bundles, pins, receipts and failed candidates
  remain caller-owned evidence without migration or automatic deletion.
  Query has no PocketIC runtime callers and does not add a Testkit dependency.
  The ICP-managed Governance smoke runner retains its current operations,
  endpoints, process ownership and cleanup timing.
- Carries the dependency-pinning validation fix from Shared 0.1.38: exception
  catalogs must contain exactly one fully validated array. Schema admission,
  evidence checks and suppression consume the same document. Malformed,
  duplicate or multiple documents fail without changing consumer inputs;
  valid catalogs retain their behavior.
  [Shared #86](https://github.com/dragginzgame/shared-tooling/issues/86).
- Refreshes the shared setup and verification guidance for prepared tools used
  by isolated formatting hooks. Query's existing hook selection is unchanged.
- Completes the maintainer's Host artifacts/filesystem/process 0.9 selection
  with published 0.9.0 and a coherent locked graph. Its library sources are
  unchanged from 0.8.10; the minor release adopts the same Shared 0.2.0 setup
  hard cut. Optional features and cache contracts remain intact.
- Loads the built probe Wasm once through the shared bounded reader and
  structural inspection before appending metadata and publishing those same
  bytes. Removes the second file read, duplicate hashing and between-read
  comparison. Module verification and `inspect-wasm` still hash the admitted
  bytes; the 64 MiB ceiling and structural bounds remain unchanged.
