# 0.65 release notes

## 0.65.0 - 2026-10-20

### Breaking

- Remove Query's public `duration` module. Import the same positive-second parser,
  rounded display function and `DurationParseError` directly from
  `ic_host_text::duration`. Duration input syntax, CLI windows and report text
  are unchanged. This completes [#71](https://github.com/dragginzgame/ic-query/issues/71).
- Remove Query's public `ledger_evidence` module and use
  `ic_host_tools::ledger_evidence` directly for ledger blocks, resource limits,
  errors and borrowed chain verification. Select Host Tools 0.31.1 with its
  `ledger-evidence` feature in consumers. Query retains certificate authentication,
  exact witness/tip-leaf admission and transaction/report policy.
- `certificate::authenticate_ledger_tip` now requires `ledger-evidence-host` and
  returns Host's `LedgerTip`; remove imports of Query's `CertifiedLedgerTip`.
  Feed the returned tip directly into Host's verifier. Plain `certificate-host`
  remains free of the ledger feature. Retain `u128` indexes, complete admission
  before hashing, immutable custody and exact chain continuity. No storage,
  cache, report, wire or payment-journal format is reset or migrated. These cuts
  implement [#78](https://github.com/dragginzgame/ic-query/issues/78); downstream
  consumers must update their imports and feature selections before upgrading.

### Changed

- Prepare Query's pinned Cargo Audit/Cargo Machete selections alongside formatters
  and the release editor before fresh release validation. A changed compiler or
  shared build-helper fingerprint no longer leaves audit tools unprepared until
  the CI gate. Standalone offline preflight uses check-only targets and refuses
  missing tools without installation; saved-validation recovery remains unchanged.
- Adopt published Platform 0.4.0 and its matching entrypoint macros. The replicated
  Governance adapter uses Platform's owned Principal for runtime calls; required
  external Candid, Agent and ledger DTOs retain their original types, encodings,
  decoder limits and error projection. Host Tools 0.31.1 shares Platform 0.4;
  Testkit 0.57 still selects Platform 0.2.2 internally. No owned runtime types
  cross that older boundary. Query already uses raw runtime calls with explicit
  external Candid codecs; Platform's retired Candid call conveniences are unused.
  No stored representations, executor identities or callback policies change.
- Require Host Artifacts, FS, Process, Text and Tools 0.31.1 or a compatible patch,
  so Registry helpers share Query's Platform 0.4 owned Principal. Convert Registry shard
  principals explicitly between Host's owned identity and Query's external
  report/Agent identity. Preserve identity bytes, interval validation, Registry
  evidence and report/cache formats. Callers naming Host types exposed through
  Query must select the matching Host minor.
- Require published IC Build 0.22.1 for its matching Host 0.31 process policy.
  Build 0.22.0's Host 0.30 cleanup type cannot accept the smoke runner's Host
  0.31 value. Preserve the runner's shared five-second TERM grace and bounded
  reaping policy without a translation shim or duplicated policy constants.
  See [IC Build #9](https://github.com/dragginzgame/ic-build/issues/9).
- Decode certified Registry and API-boundary-node unsigned `u64` LEB128 leaves
  through Host's published pure encoding feature. Remove the competing local
  decoder/re-encoder; retain field-specific diagnostics and Query's authority
  error categories. Certificate tip indexes keep their distinct `u128` codec.
  [#63](https://github.com/dragginzgame/ic-query/issues/63)

- Select Rust 1.99.1 for development and matching CI checks, retaining existing
  package MSRVs.

- Adopt Shared Tooling 0.25.4 from reviewed revision `db555ab`. Cargo-tool
  admission now identifies rejected source/receipt paths and prints the exact
  explicit setup command for the requested selection. The changed build-helper
  identity requires explicit tool setup before offline checks can admit the new
  selection; previous generations and failed attempts remain retained.
- Consume Shared's explicit Cargo-tool feature selection and failure-evidence
  collection guidance. Existing Query tool selections remain featureless;
  adopting the snapshot does not install executables or activate hooks.
  Optional selected-tool checks can request features explicitly after matching
  explicit setup; this example does not add Host's CLI to Query's default catalog:

```bash
bash scripts/dev/install-rust-tools.sh --consumer "$PWD" \
  --package ic-host-fs --version 0.31.1 --bin ic-host-file \
  --profile release --features cli --check
```

- Refresh the shared guidance for owned Wire endpoints, required external Candid
  protocols and upstream runtime maintenance. Query's existing dependency-role
  labels, grouped formatting and release-adapter selections remain in place.
- Reuse IC Build's captured compiler identity in Governance probe metadata,
  preserving schema 1, input revalidation and durable publication. Remove the
  post-compilation ambient `rustc --version` observation
  ([PR #84](https://github.com/dragginzgame/ic-query/pull/84)).
- Use Host Process's owned HTTP fixtures in native Agent body-limit, shared
  Candid query, ICRC capability and archive-callback tests. One explicit deadline
  bounds accept/read/write, and dropping the fixture cancels and joins its worker.
  Preserve the response bodies, request budgets, CBOR assertions and Agent policy
  from [PR #88](https://github.com/dragginzgame/ic-query/pull/88), addressing
  [#67](https://github.com/dragginzgame/ic-query/issues/67).
- Enable Host Tools's published `registry` feature only through
  `subnet-catalog-host` and consume its protobuf projections and routing-shard
  admission directly. Delete Query's private copies; retain transport, byte/work
  budgets, certification, replay and report/cache schemas. Prost remains a direct
  optional dependency for encoding and decoding at Query's transport boundary.
  This completes the private Registry portion of
  [#66](https://github.com/dragginzgame/ic-query/issues/66); its public timestamp
  contract is outside this patch.
