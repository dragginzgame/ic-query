# 0.66 release notes

## 0.66.0 - 2026-10-20

### Breaking

- Select published Host Artifacts, FS, Process, Text and Tools 0.32.0. Query's
  public certificate decode error now carries Host Tools 0.32's `ParseError`,
  and `certificate::authenticate_ledger_tip` returns its `LedgerTip`. Consumers
  naming or exchanging these types must select `ic-host-tools = "0.32"` with
  the applicable certificate/ledger-evidence features. No compatibility aliases,
  cache migration or wire-format reset are introduced. Retain certificate byte
  allowances, authentication, error categories and ledger witness admission.

### Changed

- Host 0.32 and Testkit 0.60 share published Platform 0.5.0 with Query. Remove
  Platform 0.4.1 from the selected lockfile while preserving external Candid,
  Agent, certificate and ledger DTO identities, reply limits and runtime behavior.
- Select IC Build 0.24.0 so the Governance smoke harness exchanges Host 0.32
  artifact, filesystem and process values consistently. Keep the five-second
  TERM grace and bounded reaping policy. Prepare the newly selected release
  metadata executable explicitly before standalone offline checks; standard
  maintainer release preflight retains its existing tool preparation.
- Select Wire 0.5.2 and its matching derive package. Its bounded encoder header
  initialization preserves the probe protocol's exact bytes and typed refusals.
- Keep Testkit's internal Host 0.31 FS/process/artifact dependencies confined to
  development. Production uses Host 0.32; Query does not exchange those older
  lifecycle types with its own Host integrations.
