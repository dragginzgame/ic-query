# 0.9 Changelog

Detailed release notes for the breaking `0.9.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## Unreleased

## 0.9.0 - 2026-07-11

### Changed

- Makes `ic-query-cli` the sole owner of Clap command definitions, option
  parsing, family dispatch, help/version handling, process output, project-root
  discovery, and command-level error/exit semantics.
- Keeps `ic-query` focused on reusable duration helpers, typed requests and
  reports, source adapters, cache and refresh mechanics, report builders, and
  text rendering. Native downstream tools use the `host` feature; pure DTO and
  renderer consumers keep default features disabled.
- Moves CLI parser and help tests beside `ic-query-cli`, while library tests
  continue to cover report behavior and public default/host APIs.

### Removed

- Removes the `ic-query/cli` Cargo feature and the library's direct optional
  dependency on Clap.
- Removes library-owned command adapters, CLI option types, command runners,
  stdout/JSON output policy, project-context discovery, and CLI-only clock,
  usage, IO, and serialization error variants.
- Provides no compatibility feature, deprecated wrapper, command alias,
  re-export shim, or alternate parser for the removed library CLI surface.
