# 0.68 release notes

## 0.68.0

- **Breaking:** select published Host Artifacts, FS, HTTP, Process, Text and
  Tools, Build and Testkit 0.64.0. Query's public
  `CertificateVerificationError::Decode` carries Host Tools 0.64's `ParseError`,
  and ledger-tip authentication returns its `LedgerTip`. Consumers naming these
  types must align their direct Host Tools dependency to 0.64 with the applicable
  features. Preserve byte admission, authentication, error projection, external
  IC bytes and schema-1 report/cache formats.
- Replace Testkit's retired PocketIC forwarding paths with
  `ic_platform::pocket_ic` imports for the compiled Governance fixture. Enable
  Platform's `pocket-ic` feature only in native development dependencies; keep
  Testkit's startup, installation and raw-reply fixture APIs. Preserve upstream
  client identities, caller selection, time control and rejection assertions.
- Align Process, Build and Testkit with the production Host packages, eliminating
  the remaining 0.63 Host identities from this lockfile. No sibling path
  dependencies or compatibility forwarding modules are introduced.
- Reprepare the lockfile-selected Build release editor and Testkit server with
  `make install-release-tools install-testkit` before their offline admission
  checks. Library dependencies keep the optional `cli` feature disabled. This
  adoption does not install executables or qualify native macOS or installed-IC
  behavior.
