# 0.18 Changelog

Detailed release notes for the `0.18.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.18.1 - 2026-07-31

### Changed

- Centralizes HTTP(S) endpoint parsing and shared scheme/host validation for
  `ic-agent` sources and the official Dashboard REST adapter. Dashboard URL
  assembly continues to enforce its stricter no-query/no-fragment base-URL
  contract and returns the same typed `InvalidEndpoint` boundary.
- Moves Dashboard usage-exit and broken-pipe classification into the existing
  top-level CLI error boundary, removing its redundant family-specific helper
  and test flow.
- Reworks the README as a concise entry point and adds a documentation index
  and CLI usage guide. The updated guides distinguish authority, freshness,
  collection modes, cache policy, CLI component-topology diagnostics, and the
  exact-version joined topology library API.

### Compatibility

- Command grammar, report JSON, cache schemas, collection behavior, typed
  public errors, and public Rust exports are unchanged.
- This cleanup adds no CLI surface or compatibility aliases.

## 0.18.0 - 2026-07-30

### Added

- Adds a bounded live official Dashboard canister detail report:

  ```bash
  icq ic canister info ryjl3-tyaaa-aaaaa-aaaba-cai
  icq ic canister info ryjl3-tyaaa-aaaaa-aaaba-cai --format json
  ```

- Adds the `ic_query::ic` public family with `IcCanisterRequest`,
  `IcCanisterReport`, proposal-linked upgrade rows, text rendering, typed host
  errors, `IcCanisterSource`, custom-source construction, and the
  `LiveIcSource` authority adapter.

### Guarantees

- Uses the official Dashboard `/api/v3/canisters/{canister_id}` resource and
  retains the explicit API base endpoint, report retrieval timestamp,
  Dashboard row update timestamp, and collector.
- Preserves raw nullable canister classification and upgrade history, raw
  name/language/module-hash strings, canonical canister/Subnet/controller
  principals, and raw proposal execution seconds and ids.
- Canonically orders controllers and newest-first upgrade history. It rejects
  duplicate controllers, duplicate proposal ids, malformed principals and
  hashes, source identity mismatches, and source provenance mismatches.
- Explicitly reports `certified: false` and
  `point_in_time_guaranteed: false`; Dashboard analytics do not inherit
  Registry versions or certified canister authority.
- Validates a canister principal and an HTTP(S) base endpoint before making a
  live request. Non-success HTTP responses, transport failures, and JSON
  decoding failures remain distinct typed errors.
- Rejects the top-level `--network` option for the endpoint-identified `ic`
  family and directs callers to `--source-endpoint`.
- Keeps this bounded point lookup live-only. It does not read, write, or
  invalidate a cache, and library code emits no process output.

### Scope

- This slice does not add complete canister enumeration, management-canister
  calls, certified controller/module proofs, network metrics, boundary nodes,
  replica reporting, mutation behavior, or compatibility aliases.
