# 0.38 Changelog

## 0.38.0 - Unreleased

### Canister-native NNS Governance boundary

- Keeps the existing two-crate workspace: `ic-query` owns reusable reporting
  and runtime adapters, while `ic-query-cli` remains the only CLI crate.
- Adds one `canister` runtime feature, exposing the four bounded
  direct NNS Governance reports without enabling the native host, Tokio,
  `ic-agent`, Reqwest, or filesystem cache graph. `ic-query-cli` retains no
  feature matrix and always uses the full native host surface.
- Hard-cuts the direct Governance request, source, and schema-1 provenance
  contracts to one tagged enum that distinguishes native replica queries from
  replicated inter-canister calls. Transport assurance is derived from the
  variant, transport-incompatible field combinations are unrepresentable, and
  malformed native endpoints fail validation before source invocation.
- Makes native and canister transports share one caller-runtime async
  source, validation, and report-assembly path.
- Leaves persistence, scheduling, retries, cycle budgeting, and stable-memory
  policy with the consuming canister.

Each built-in canister source operation makes exactly one `Call::bounded_wait`
call to the fixed mainnet Governance canister, attaches no cycles, enforces an
8 MiB raw response ceiling before Candid decoding, and maps call rejects,
timeouts, encoding, decoding, source-evidence, and payload validation failures
to typed errors. The caller supplies collection time and owns execution
context, scheduling, retry, cycle-budget, and durable-state policy.

Detailed design: [0.38 canister-native NNS Governance reporting](../design/0.38/0.38-design.md)

### Release tooling

- Runs `cargo audit` against a fresh disposable RustSec checkout on every
  dependency gate instead of its long-lived shared advisory cache. This avoids
  duplicate-ID and related parse failures from files retained after upstream
  advisory moves, without weakening advisory freshness or deny rules. The
  helper removes its exact temporary checkout on success and failure.
