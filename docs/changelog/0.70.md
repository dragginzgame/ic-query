# 0.70 release notes

## 0.70.0

- **Breaking:** select published Host Artifacts, FS, HTTP, Process, Text and
  Tools, Build and Testkit 0.66.0. Consumers naming Host types exposed by Query
  must align to Host 0.66, including certificate parse errors and authenticated
  ledger-tip values. Certificate policy, report/cache formats and schema-1
  evidence remain unchanged.
- Borrow the PocketIC client through Testkit's accessor and keep its owning
  instance alive for the complete Governance test. Query does not detach the
  client or take over server ownership; synchronous client deletion still
  precedes managed-server teardown.
- Select published Wire 0.6.7 without changing the probe's native Serde/Postcard
  protocol, method identity, raw reply evidence or traversal allowances. Keep
  Platform 0.6.10 and Metrics 0.15.7 with their existing feature selections.
- Refresh Shared Tooling to 0.26.8 at
  `0b07c2a3163a5a66328e100b553baf93afd8ed07` through the canonical exporter.
  Admit an existing install owner's lock cleanup without accepting a replaced
  or malformed claim. Source-cache initialization no longer takes a global
  installation lock; Cargo retains download serialization and selected tool
  slots retain build exclusion. Offline checks remain immediate.
- Rerun `make install-tools install-testkit` once to select the unchanged
  executable pins under the new Cargo build-policy identity, including Build
  and Testkit. Keep `cli` confined to executable setup/admission; library
  consumers retain their capability features. Retain previous tool generations,
  source-preparation slots and diagnostic evidence.
