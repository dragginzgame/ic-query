# 0.11 Changelog

Detailed release notes for the breaking `0.11.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.11.1 - 2026-07-29

### Changed

- Replaces the identical node, data-center, node-operator, node-provider, and
  exact-version topology live source-request DTOs with
  `ic_query::nns::NnsInventorySourceRequest`. Every public live Registry
  inventory source now rejects non-mainnet requests before constructing an
  agent. This is a breaking library hard cut without compatibility aliases.
- Consolidates component-labelled NNS topology, inventory, and subnet-catalog
  cache failures under the public `HostCacheError` and `CacheFileError`, while
  retaining typed missing, read, parse, schema, network, lock, and atomic-write
  failures.
- Shares exact node-to-operator-to-provider relation resolution across
  Registry projections. Missing records remain relation-specific, missing
  operator context retains every canonically ordered referencing node, and an
  empty provider principal remains `MissingNodeProviderPrincipal`.
- Shares cache freshness and topology Registry-provenance projection between
  their existing consumers.
- Shares SNS neuron and proposal refresh-attempt reading, validation, and
  refresh page-size validation without changing report schemas, cache formats,
  or CLI behavior.

## 0.11.0 - 2026-07-29

### Added

- Adds `NnsSubnetTopologyReport`, `NnsSubnetTopologyRow`, and
  `NnsSubnetNodeProviderRow` as a canonical Subnet-oriented topology snapshot.
  The live source resolves one Registry version, reads every joined
  Subnet/node/operator relation at that version, preserves raw
  application/system/cloud-engine/unknown kinds, and excludes separately
  sourced governance enrichment.
- Adds one atomically published `.icq/subnet-topology/<network>/report.json`
  cache and separately named APIs for cache-only load, explicit refresh,
  refresh-if-missing, and refresh-if-stale behavior.
- Adds typed validation for canonical ordering, unique Subnets/providers,
  principal syntax, positive provider counts, exact provider-to-Subnet node
  sums, and missing or contradictory Registry relations. The public live
  source rejects non-mainnet requests before agent construction, required
  node and node-operator `key_not_present` responses become relation-specific
  errors with deterministic referencing-node context, and other Registry
  errors retain their transport details.

### Changed

- Adds the required `registry_versions` field to
  `NnsTopologyProvidersReport`, making this a breaking public library change.
  Aggregate provider reports retain every component Registry version instead
  of dropping the input provenance.
- Centralizes raw Registry Subnet-kind conversion across catalog, node, and
  exact-version topology projections, preserving application, system,
  cloud-engine, and unknown output classifications.
- Updates the host-only `ic-agent` dependency from 0.48.1 to 0.49.2. The
  agent's request-status polling uses the maintained `backon` implementation,
  and HTTP retries now treat temporary 503 responses like 429 responses with
  the same six-retry bound.
