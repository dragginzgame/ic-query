## 0.21.0 - 2026-08-01

### Added

- Adds two focused native Cycle Minting Canister reports:

  ```bash
  icq system xdr
  icq system xdr --format json
  icq system cycles
  icq system cycles --format json
  ```

- Adds `CmcSourceRequest`, `CmcSource`, `LiveCmcSource`, typed rate,
  certification, context, XDR, cycles, and error DTOs, custom-source builders,
  and text renderers under `ic_query::system::cmc`.
- Adds the `icq system` mainnet authority family and honors the existing
  top-level `--network` option. Both public builders and the public live source
  reject non-`ic` networks before invoking a source or constructing an agent.
- Adds a focused certified-CMC design contract and updates command, library,
  adapter, authority, and 1.0 roadmap documentation.

### Guarantees

- Makes exactly one native mainnet CMC
  `get_icp_xdr_conversion_rate` query per report. The command is live-only and
  never paginates, fans out, enumerates canisters, or reads or writes a cache.
- Authenticates the CMC system certificate through `ic-agent`, verifies the
  hash-tree digest against the CMC `certified_data` value, requires the native
  `ICP_XDR_CONVERSION_RATE` leaf, and requires that leaf to equal the Candid
  encoding of the returned rate. Invalid CBOR, certificate authentication,
  certified-data, leaf-presence, and leaf-value evidence remain typed errors.
- Preserves `timestamp_seconds` and `xdr_permyriad_per_icp` as raw CMC values
  alongside CMC principal, endpoint, collection timestamp, collector, full
  certificate/hash-tree hex, byte counts, and explicit successful verification.
  Text formats the permyriad rate to four decimal places without replacing
  the JSON integer.
- Derives `cycles_per_icp` as
  `xdr_permyriad_per_icp * 1_000_000_000_000 / 10_000` using `u128`, and
  preserves the formula, one-trillion-cycles-per-XDR value, and its explicit
  `ic_protocol_constant` authority label in the cycles report.
- Does not claim or synthesize total cycles minted. That value is not exposed
  by the current public CMC Candid interface, and the CMC Prometheus response
  is explicitly uncertified.

### Internal consolidation

- Centralizes certificate decoding, authentication, hash-tree decoding, and
  canister `certified_data` digest validation for CMC and ICRC tip evidence.
  Each authority still owns its native witness-label and leaf-value checks.
  Existing ICRC tip report JSON, errors, command grammar, and verification
  guarantees are unchanged.

### Compatibility

- This is additive CLI and Rust API surface. Existing command behavior,
  report JSON, cache paths, and cache schemas are unchanged.
- This release adds no compatibility aliases, fallback readers, mutation
  behavior, hidden CMC calls, or implicit network access.
