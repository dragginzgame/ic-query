# 0.63 release notes

## 0.63.0

### Breaking

- Adopt published Host Tools 0.29 certificate decoding through `serde_cbor`,
  removing Ciborium from the selected graph. Host follows the IC Agent codec
  for recursion and semantic tags; Query no longer supplies a parser-depth
  policy. Remove the final `depth` argument from `certificate::authenticate`
  calls and the `depth` field from `CertificateEvidenceLimits` initializers.
  Existing callers must rebuild against the new API.
- Preserve pre-parse byte allowances, combined certificate/witness byte
  admission, strict schema decoding, trailing-data categories, native parse
  error evidence, Agent authentication before witness admission and exact
  witness commitments. CMC and ICRC now use the codec recursion policy instead
  of Query's former 64-level bound. No parser emulation or fallback is added.
  See [Host #201 — Replace certificate Ciborium backend with serde_cbor while preserving strict bounds](https://github.com/dragginzgame/ic-host-tooling/issues/201)
  for the upstream decision to retire configurable depth.

### Changed

- Replace the confined cache backend with published Host FS 0.29 directory and
  file-entry capabilities. Query retains cache roots/paths, 0700/0600 creation,
  rejection of group/other write permissions, per-file/aggregate byte budgets,
  candidate selection, 16x entry limits, depth limits and public error projection.
  Keep publication and coordination relative to the admitted parent after renames,
  and retain unlink-completed evidence when parent synchronization fails. Remove
  direct `cap-std`/`cap-fs-ext` declarations and generic filesystem plumbing.
- Compile Governance fixture WAT using Host Artifacts' test-only `wasm-text`
  feature with explicit 1 MiB source and output allowances. Remove direct `wat`;
  its parser remains a private transitive Host dependency. Existing typed Candid
  replies, method exports and Testkit execution policy remain Query-owned.
- Use Host Process's signal-action guard for the smoke harness. Query selects
  SIGINT/SIGTERM and retains its lock-free cancellation recorder and bounded
  cleanup policy. Keep `libc` for signal constants and native process fixtures;
  cover prior-disposition restoration in an isolated child process.
- Admit the existing test-only refresh-lock inspector in focused cache profiles,
  matching its implementation gate so those profiles compile independently.
- Enforce the direct capability/WAT ownership boundary with the shared dependency
  checker, including aliases and normal/build/development/target declarations.

- Delete the unused root Ciborium catalog entry left after the fixture codec
  migration, and correct the dependency-role guide. Neither Query crate declares
  or imports Ciborium; production certificate decoding remains Host-owned.
- Refresh the canonical Shared Tooling snapshot to 0.25.0 at `2a79f5f9`, adopting
  the released graph checker, grouped formatter defaults, external-IC dependency
  boundary and repository-file policy. Preserve the existing host, IC and common
  Cargo tool catalogs; remove Query's identical formatter overrides.
- Delegate manifest and lock candidate rendering to the published IC Build
  package selected in `Cargo.lock` (0.21.0). Retire both
  standalone Perl editors through the snapshot exporter. Query retains its
  authenticated source, release file set, local dependency projection, notes,
  source/index checks and retry/recovery policy. Rendering accepts an absolute
  prepared editor and an explicit 8 MiB input allowance; missing tools and input
  refusal stop before metadata replacement.
- Adopt IC Build 0.21.0’s Clap-based editor help, version and argument handling,
  preserving rendering operations, bounded input refusal and MSRV 1.91.0.
- Align Build 0.21 with Host Process 0.29 so the smoke harness keeps the same
  cleanup-policy type, TERM grace and bounded reaping behavior.
- Add editor preparation to explicit tool setup and maintainer release preflight.
  Offline checks only admit the existing selection. Qualify consumer rendering,
  refusal, partial preparation retries and selected-source checks using the real
  published editor with simulated release Git effects.
