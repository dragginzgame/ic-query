# 0.28 Changelog

Detailed release notes for the `0.28.x` release line.

## 0.28.1 - 2026-08-05

### Presentation and snapshot validation

- Separated text provenance and summary preambles from their tables with a
  blank line. Later titled evidence tables are distinct visual sections; JSON
  output is unchanged.
- Reject empty live or custom mainnet node snapshots instead of publishing an
  implausible complete network observation.
- Validate cached rows without mutating them. A cache whose node rows are not
  in strict canonical principal order is now typed as invalid and is repaired
  only by the existing explicit read-through policy; strict cache-only loads
  remain strict.
- Apply the same principal, uniqueness, provider-name, required-value,
  assignment, scope, and canonical-order checks to pure snapshot projections,
  preventing manually constructed snapshots from bypassing the source
  contract.

## 0.28.0 - 2026-08-04

### Observed operational status

- Added node, Subnet, and node-provider status reports over one complete
  official Dashboard v3 `/nodes` response. The live adapter performs one
  unfiltered request, follows no redirects or cursors, makes no per-row calls,
  rejects bodies above 8 MiB, and accepts at most 10,000 rows.
- Preserved raw node status/type/reward, assignment, alert, provider/operator,
  GuestOS, TEE, IP, connectivity, hardware, data-center, owner, and region
  evidence. Unknown future statuses remain raw and count conservatively as
  non-up.
- Added exact and unique-prefix targeting plus default attention and `--all`
  views. Targets and view options do not alter collected snapshot identity.
- Added Subnet down-only and conservative non-up distances from
  `floor((n - 1) / 3)` without presenting either Dashboard observation as
  certified consensus evidence.
- Added shared status-by-assignment totals at snapshot and provider level, so
  assigned, unassigned, API-boundary, and unknown-assignment up/non-up counts
  remain directly comparable without a second projection flow.
```bash
icq nns node status
icq nns node status <node-or-prefix> --json
icq nns subnet status <subnet-or-prefix> --all
icq nns node-provider status --refresh
```

### Cache and authority

- Added one atomic cache at
  `ic/ic/nodes/operational-status/full.json`, shared by all three projections.
  Ordinary views visibly refresh content that is missing, recoverably invalid,
  or older than 60 seconds; `--refresh` forces replacement. Strict load,
  refresh, refresh-missing, and refresh-stale library operations remain
  distinct.
- Registered the snapshot's age and automatic-recovery policies with
  `icq cache status`. Cache and report metadata record official Dashboard
  authority, the explicit endpoint and timestamp, `certified: false`,
  `point_in_time_guaranteed: false`, and the default public-mainnet scope's
  cloud-engine exclusion.
- Enforced the mainnet `ic` network before any refresh source call. Custom
  source data is treated as untrusted and validated for exact provenance,
  bounds, canonical principals, uniqueness, ordering, assignment consistency,
  and deterministic provider names before publication.

### Terminology hard cut

- Renamed `icq nns topology health` to `icq nns topology check`. The public
  topology report/row types, builders, renderer, and schema constant use the
  same terminology. The operation checks component-cache consistency and is
  not operational node health.
- Removed the prior command and public names without aliases, wrappers, legacy
  readers, or anti-resurrection tests.

```bash
icq nns topology check
```

### Library and documentation

- Added public pure DTOs, snapshot-to-view projection helpers, and text
  renderers under `ic_query::ic`, available without default features.
- Added the focused host-only `IcNodeStatusSource`, live/custom snapshot
  builders, cache requests, read/refresh builders, typed cache/projection
  errors, and fixture-backed public API coverage.
- Updated the README, CLI guide, adapter contract, cache inventory, roadmap,
  and documentation index for the new authority and command surface.
