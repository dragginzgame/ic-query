# 0.12 Changelog

Detailed release notes for the breaking `0.12.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.12.0 - 2026-07-29

### Changed

- Makes `ic_query::nns::LiveNnsSource` the single built-in live adapter for
  supported NNS Registry, governance, topology, and inventory source
  capabilities. Small per-report source traits remain available for focused
  fixture and downstream implementations.
- Replaces `NnsInventorySourceRequest`, `NnsProposalSourceRequest`,
  `NnsRegistrySourceRequest`, and `SubnetCatalogSourceRequest` with the shared
  `ic_query::nns::NnsSourceRequest`. This is a breaking library hard cut
  without aliases, deprecated wrappers, or compatibility re-exports.
- Enforces the mainnet-only contract before constructing an agent for direct
  live Registry, subnet-catalog, inventory, proposal, and exact-version Subnet
  topology capability calls.
- Shares exact-version Registry relation acquisition between node inventory
  and Subnet topology collection while preserving one resolved Registry
  version and relation-specific missing-record errors.
- Consolidates fragmented NNS cache, refresh, request, path, macro, and text
  projection helpers into their owning modules. Public report fields, cache
  formats, refresh policy, CLI behavior, and JSON output are unchanged.
- Defines the reporting-adapter direction for broader NNS, SNS, ICRC index,
  Dashboard API, CMC/XDR, Internet Identity, Bitcoin, and protocol-canister
  coverage while keeping provenance and follow-up queries explicit.

### Removed

- Removes the nine replaced family-specific live source types:
  `LiveNnsRegistrySource`, `LiveNnsRegistryRefreshSource`,
  `LiveNnsNodeSource`, `LiveNnsDataCenterSource`,
  `LiveNnsNodeOperatorSource`, `LiveNnsNodeProviderSource`,
  `LiveNnsProposalSource`, `LiveNnsTopologySource`, and
  `LiveNnsSubnetTopologySource`.
