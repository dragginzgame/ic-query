# 0.25 Changelog

Detailed release notes for the `0.25.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.25.12 - 2026-08-02

### Changed

- Removes five repeated test-only Dashboard option parsers plus the separate
  canister-count parsing flow.
- Uses one IC-family test harness to parse ordinary string slices through the
  selected production Clap command and `from_matches` projection for canister,
  metric, and network-resource options.

### Compatibility

- Production command parsing, grammar, defaults, help and diagnostics, public
  Rust APIs, report JSON, text output, request bounds, source calls, cache
  behavior, and network behavior are unchanged.

## 0.25.11 - 2026-08-02

## 0.25.10 - 2026-08-02

  dedicated strict-storage, refresh/publication, local-report, and existing
  refresh-attempt owners.

## 0.25.0 - 2026-08-01

### Added

- Expands `SnsNeuronRow` and the existing `sns neuron list` and refresh flows
  with the fixed-size native Governance fields already returned by
  `list_neurons`: source NNS neuron id, auto-stake maturity, aging timestamp,
  dissolve state, voting-power percentage multiplier, vesting period, and
  neuron fees.
- Adds the public `SnsNeuronDissolveState` model using the native
  `DissolveDelaySeconds` and `WhenDissolvedTimestampSeconds` alternatives.
- Preserves every added field as raw JSON evidence. Text output remains a
  compact view over that complete row.

### Changed

- Applies one canonical neuron-row validator to bounded custom-source results,
  complete refresh pages, and loaded caches. It enforces lowercase even-length
  id hex, exact derived creation-time text, unique ids, and the requested live
  limit.
- Validates cache schema and network headers before decoding the complete row
  model. An older schema therefore returns the typed unsupported-schema error
  even when its row shape no longer deserializes as the current model.

### Bounds And Compatibility

- Adds no query, follow-up, pagination, fanout, or cache write beyond the
  existing bounded `list_neurons` and explicit complete-refresh flows.
- Deliberately omits variable-size permission, followee, topic-followee, and
  pending maturity-disbursement graphs from collection rows. A later detail
  report may expose those through one explicit neuron lookup.
- Advances SNS neuron report and cache schemas to version 2. Version-1 neuron
  caches are rejected as unsupported and require an explicit refresh; there
  is no migration, fallback reader, alias, or legacy row shape.
