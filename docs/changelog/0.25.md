# 0.25 Changelog

Detailed release notes for the `0.25.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.25.3 - 2026-08-01

### Changed

- Separates official Dashboard canister, metrics, and network-resource command
  construction, typed option parsing, execution, and focused tests into their
  cohesive CLI owners behind the existing `ic` facade.
- Keeps the facade responsible only for the shared error type, root command
  composition, and family dispatch.

### Compatibility

- CLI commands and help, public Rust APIs, report JSON, text output, request
  bounds, endpoint defaults, source-call counts, cache behavior, and network
  behavior are unchanged.

## 0.25.2 - 2026-08-01

### Changed

- Separates the NNS neuron cache model, paths, refresh-attempt evidence, page
  collection, publication, refresh orchestration, and cached report projection
  into cohesive internal owners behind the existing cache facade.
- Keeps the neuron-specific public Governance row validation, ordered cursor
  walk, API-exhaustion requirement, atomic publication, refresh lock, attempt
  evidence, cache-only list/detail projection, and status reporting intact.

### Compatibility

- Public Rust paths and types, CLI behavior, report JSON, cache paths and
  schemas, validation and error mapping, text output, refresh policy, progress
  events, source calls, and network behavior are unchanged.

## 0.25.1 - 2026-08-01

### Changed

- Corrects README and CLI documentation that described every report schema as
  version 1 now that SNS neuron reports and caches use version 2.
- Shares the identical optional-value, case-insensitive text, and directional
  ordering primitives used by NNS and SNS proposal views while retaining their
  separate filters and report semantics.
- Moves generic optional scalar text rendering to the shared text-value owner
  and removes a redundant SNS proposal wrapper.
- Folds the one-function dispatch and one-macro test-helper leaves for NNS data
  centers, node operators, and node providers into their owning command
  modules.

### Compatibility

- Public APIs, CLI behavior, report JSON, cache paths and schemas, sorting,
  text output, source calls, and network behavior are unchanged.

## 0.25.0 - 2026-08-01

### Added

- Expands `SnsNeuronRow` and the existing `sns neuron list` and refresh flows
  with the fixed-size native Governance fields already returned by
  `list_neurons`: source NNS neuron id, auto-stake maturity, aging timestamp,
  dissolve state, voting-power percentage multiplier, vesting period, and
  neuron fees.
- Adds the public `SnsNeuronDissolveState` model using the native
  `DissolveDelaySeconds` and `WhenDissolvedTimestampSeconds` alternatives.
- Preserves every added field as raw JSON evidence. Text output remains a
  compact view over that complete row.

### Changed

- Applies one canonical neuron-row validator to bounded custom-source results,
  complete refresh pages, and loaded caches. It enforces lowercase even-length
  id hex, exact derived creation-time text, unique ids, and the requested live
  limit.
- Validates cache schema and network headers before decoding the complete row
  model. An older schema therefore returns the typed unsupported-schema error
  even when its row shape no longer deserializes as the current model.

### Bounds And Compatibility

- Adds no query, follow-up, pagination, fanout, or cache write beyond the
  existing bounded `list_neurons` and explicit complete-refresh flows.
- Deliberately omits variable-size permission, followee, topic-followee, and
  pending maturity-disbursement graphs from collection rows. A later detail
  report may expose those through one explicit neuron lookup.
- Advances SNS neuron report and cache schemas to version 2. Version-1 neuron
  caches are rejected as unsupported and require an explicit refresh; there
  is no migration, fallback reader, alias, or legacy row shape.
