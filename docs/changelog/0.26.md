# 0.26 Changelog

Detailed release notes for the `0.26.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,

## 0.26.0 - 2026-08-03

### Added

- Adds `SnsNeuronSource` for one exact native Governance `get_neuron` lookup,
  separate from the existing `SnsNeuronsSource` bounded-list and refresh-page
  capability.
- Adds no-default-feature detail DTOs and rendering for current principal
  permissions, raw permission codes and native labels, complete pending
  maturity-disbursement destination accounts, legacy followees, topic
  followees, and fixed-size neuron state.
- Adds neuron-local tri-state observations for maturity mint conversion and
  manual maturity staking. Unknown future codes and anomalous code 0 fail
  closed as `unassessable`; known prohibited codes or pending maturity
  disbursements produce `violated`.
- Adds the live-only exact detail command:

```bash
icq sns neuron info 1 000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f --json
icq sns reward checkpoint 1 --max-pages 10 --json
icq sns reward diff before-checkpoint.json after-checkpoint.json --json
```

- Adds `SnsRewardSource` and the live `sns reward checkpoint` command. The
  collector strictly exhausts native `list_neurons` pages while bracketing the
  walk with complete nervous-system parameters, latest reward event, and
  running SNS version responses.
- Adds versioned checkpoint rows and reports containing raw unstaked, staked,
  and checked combined maturity, all current principal permissions, complete
  pending maturity-disbursement accounts, auto-stake state, collection bounds,
  aggregate totals, and tri-state policy findings.
- Adds a no-host pure checkpoint validator. It treats serialized reports as
  untrusted evidence and recomputes row identities, ordering, counts, maturity
  totals, policy findings, bracket stability, timestamps, target principals,
  version hashes, and query-count evidence from raw fields.
- Adds a pure no-host reward-diff builder, typed `valid | no_allocation |
  invalid` outcomes, signed per-neuron maturity deltas, complete stable target
  references, typed invalid reasons, and positive-allocation numerator and
  denominator evidence.
- Adds host-only strict checkpoint file loading and the local-only `sns reward
  diff` command. The command accepts only two explicit file paths and output
  format; network and source-endpoint controls are rejected or absent because
  it performs no live call.

### Changed

- Enforces exactly 32-byte SNS neuron identifiers, represented as 64 lowercase
  hexadecimal characters, for exact input and validated source rows.
- Validates custom exact-detail sources against the requested neuron identity,
  canonical principals and subaccounts, unique permission principals and
  codes, followee identifiers, and recomputed policy observations.
- Makes the public nervous-system parameter report preserve raw default
  followees so checkpoint brackets compare the complete relevant Governance
  response rather than only selected fields.
- Fails checkpoint collection on duplicate, overlapping, or non-increasing
  neuron ids; invalid full-page cursors; cursors on short exhausted pages;
  bracket changes; arithmetic overflow; and collection beyond Governance's
  validated `max_number_of_neurons`, capped at the protocol ceiling of
  200,000. `--max-pages` is diagnostic only and cannot publish an incomplete
  checkpoint.
- Recomputes loaded checkpoint rows, summaries, policy findings, event and
  version brackets, timestamps, canonical principals, and report counts before
  comparison. Serialized derived totals and statuses never become diff inputs.
- Requires stable canister identity, strictly increasing canonical reward-event
  positions, a later actual distribution timestamp than the baseline
  collection, native round continuity, observed-satisfied policy on both
  sides, non-negative explained neuron deltas, and exact aggregate and
  per-neuron reconciliation to `distributed_e8s_equivalent`. A missing neuron,
  unsupported new-neuron creation timestamp, hidden maturity conversion,
  skipped or uncovered event, or arithmetic failure remains a typed invalid
  reason.

### Operations

- Exact detail performs targeted SNS discovery followed by one Governance
  query: three live calls in total. It never reads or writes the complete
  neuron cache and does not add identity handling or mutation calls.
- A checkpoint with `N` neuron pages performs `N + 8` client queries, including
  targeted discovery and both sides of the three Governance brackets. It does
  not query ballots, ledgers, transactions, or one detail method per neuron.
- Checkpoint text output is bounded to summary evidence. `--json` retains every
  raw row for explicit caller-managed persistence; the command creates no
  implicit cache or checkpoint file.
- Reward diff is local-only and writes no files. Its text output bounds invalid
  reason detail; JSON retains every joined row and invalid reason. Local files
  explicitly report that their content is not authenticated.
- Existing fixed-size neuron report and cache schema 2 are unchanged.

### Compatibility

- This is a pre-1.0 hard cut for custom sources that previously returned
  non-native-length neuron identifiers. No compatibility parser, alias, or
  legacy cache branch is retained.
- The public nervous-system parameter DTO now requires its native
  `default_followees` field. Custom parameter sources must preserve it rather
  than projecting only a selected parameter subset.
- `SnsGovernanceParameters` is now the strict JSON/report DTO rather than a
  Candid wire type. Native Candid decoding uses an internal complete wire
  model before projection; downstream code that decoded Governance responses
  directly into the public report type must use its own wire model or the
  built-in source adapter.
