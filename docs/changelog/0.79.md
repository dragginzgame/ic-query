# 0.79 release notes

## 0.79.0

### ⚠️ Breaking

- Adopt published Platform 0.15.2 for Query's public ledger types and canister
  runtime. Custom `IcrcTipCertificateSource` implementations now return its
  `ICRC3DataCertificate`. Runtime handles also have Platform 0.15 identity;
  rebuild all runtime consumers on that line, including timer and endpoint
  integration libraries when used.
- Preserve external Agent, Candid and certificate identities, codec behavior,
  resource budgets, commands and report/cache schemas. Query uses Host Artifacts
  directly for gzip. The public Platform type identity change requires this
  minor release.
- Adopt Host Tools 0.75.0 certificate errors and ledger-evidence values exposed
  by Query. Consumers naming `certificate::ParseError` or `ledger_evidence::LedgerTip`
  must align their direct Host Tools dependency to 0.75.

- Replace the family-specific NNS, SNS, CMC and CloudEngine source request
  types with `ic_query::report::CollectionSourceRequest`. Fields and constructor
  arguments retain explicit network, endpoint, timestamp and collector values;
  each source family continues to enforce its own admission policy.
- `IcrcIndexData` now exposes `Found(String)` and `Unavailable(String)` outcomes.
  Custom index sources select one outcome; transport failures remain `IcrcError`.
  Report JSON keeps its optional `index_canister_id` and `index_error` fields.
- Topology coverage reads node, provider, operator and data-center inventories
  in that order and stops on the first failure. It no longer loads, refreshes or
  fails on the unrelated Subnet Catalog. Summary, versions and check still read
  all five components, with the Subnet Catalog first.

- Governance parameter, proposal list/detail and neuron list/detail reports now
  compose public `SnsReportContext` as `context`. Topology summary and coverage
  compose `NnsTopologyJoinCoverageCounts` as `join_coverage`; Serde flattens both
  payloads into the existing JSON fields. Read Rust fields through these payloads.
- Topology read builders and source callbacks accept `nns::NnsInventoryListRequest`.
  Construct it with `NnsInventoryCacheRequest`, endpoint and caller clock. Refresh
  still composes `read` plus topology-only dry-run policy; component export and
  cache policies are unchanged. The former topology read type is removed.
- NNS and SNS proposal requests use `report::SortDirection::{Asc, Desc}`; family
  sort keys retain their own defaults. The family-specific direction types are
  removed without compatibility re-exports.
- Custom `MainnetSnsToken` sources provide `ledger_index: IcrcIndexData`, selecting
  `Found(String)` or `Unavailable(String)`. SNS retains discovery failures,
  including transport failures, alongside token metadata; native ICRC transport
  errors remain fatal. Emitted optional index/error fields are unchanged.

### 🧭 Migration Notes

- Query, Host Tools and Testkit select Platform 0.15.2 and canonical Platform
  Types 0.15.1. Registry helpers return Platform's owned Principal; the required
  external Candid and Agent boundaries retain the external Principal identity
  through explicit conversions. Protocol bytes and cache identities are unchanged.
- Query uses Wire 0.13's core codec. Optional identity schemas belong to Wire's
  `platform-types` feature and endpoint integration is independently supplied by
  `ic-wire-endpoint`; Query enables neither. Runtime consumers must align their
  integration suppliers on Platform 0.15 and canonical Types 0.15.
- Metrics 0.24.0 remains private arithmetic with validated Serde transport and
  `native-wire` disabled. Published Testkit 0.75.0 still requires arithmetic-only
  Metrics 0.23.2 internally; that separate version is development-only. Production
  graphs exclude Wire. Codec bytes, admission budgets, report fields and schema-1
  caches remain unchanged; no reset is needed.

### 🔧 Changed

- Adopt the independently published Foundation 0.73.1 packages (Host Artifacts,
  FS, HTTP, Process, Text and Build) and integration 0.75.0 packages (Host Tools
  and Testkit). Prepare the locked Build metadata editor and Testkit CLI through
  Query's existing shared installer. Retain Rust 1.91 support.
- Adopt Metrics 0.24.0 and Wire 0.13.0, preserving checked measurement arithmetic,
  integer rounding and bounded request/reply admission. Host Artifacts now selects
  Wasm Parser/Encoder 0.263; unrelated lockfile selections are retained.
- Refresh Shared Tooling to committed revision
  `f4f431627290e18f0ccc1e5f8525d16b197cf7c3` (0.27.22) through the
  canonical exporter. Adopt its catalog checks and release/publication adapters,
  completing root declarations for all three Query workspace members. Keep
  Query's single coordinated version, existing crate paths, release restrictions
  and consumer-owned qualification scope.

### 🩹 Fixed

- Match internal helper gates to their consumers so focused Subnet Catalog and
  topology builds compile without unused-code warnings.
- Check the current Wire-free production contract in native CLI and library
  graph fixtures as well as portable and canister fixtures. Remove the stale
  expectation that native Metrics enables Wire metadata.

### 🧹 Cleanup

- Build topology checks from shared version, freshness and relation evidence
  without assembling classification totals for a discarded summary report.
- Parse ICRC analytics arguments into their public requests, keeping command
  defaults, cursor filters, sort values, endpoint selection and caller clocks.
- Use the shared cache lifecycle for SNS proposal read-through loading. Only a
  missing snapshot authorizes refresh; rejected content and filesystem errors
  retain their current failure behaviour.
- Keep parsed routing keys paired with their rows through canonical ordering
  and structural validation. Carry matched subnet rows through prefix
  resolution, preserving duplicate handling and sorted ambiguity diagnostics.
- Style SNS metadata cells using row status while retaining Host escaping and
  alignment, CLI terminal policy and `NO_COLOR`. Group related SNS CLI values
  under one owner. JSON and persisted schema-1 contracts remain unchanged;
  existing caches need no reset.

- Parse native ICRC allowance, account-history page/list/refresh, transactions and
  archive options directly into public requests plus output format. Keep shared
  ledger/account input scopes, explicit cache roots, caller clocks and cache-only
  list/status behavior.
- Move SNS identity/provenance into each matching governance envelope as one
  value. Reuse `CollectionSourceRequest::from_unix_secs` for SNS acquisition and
  the shared inventory request's live provenance.
- Carry topology coverage counts and their five-pair ordering in one payload
  through summary, coverage and text rendering. Check still projects evidence
  directly, without building a summary.
- Carry one reward checkpoint assessment through reconciliation, retaining
  recomputed summaries for invalid evidence and refusing row allocation until
  both checkpoints validate. Public validation remains fail-fast.
- Inline private NNS proposal sort labels in their canonical matches and
  co-locate the four inventory resolver adapters with their builders. Keep
  family-specific errors, exact/prefix resolution and ambiguity evidence.
