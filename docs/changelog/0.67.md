# 0.67 release notes

## 0.67.5

- Select the minimum compiler through Cargo's inherited workspace Rust version
  for both Make and native CI, preserving explicit `MSRV` overrides. Bootstrap
  CI discovery with its installed compiler, without fetching dependencies or
  implicitly installing the repository's development compiler.
- Replace the host guide's superseded adoption diary and obsolete blockers with
  current prerequisites, native qualification boundaries and exact delivered
  evidence. Retain historical investigations through committed history and CI
  records rather than carrying old pin selections as current setup advice.
- Refresh the canonical Shared Tooling snapshot to 0.26.4 at
  `dc1ced7e240e90f0c6daa89fb6248fcb074164eb`. Keep the existing executable pins
  and explicitly select all five Query tools before the shared Make interface.
  Prepare the selected IC bundle before offline admission; previous bundles and
  diagnostic evidence remain retained.
- Monitor the consumer Makefile alongside CI inputs so executable-selection
  changes cannot pass unnoticed during validation. Qualify the selected arguments
  and fail-fast IC/Rust preflight order in consumer setup fixtures.
- Adopt bounded failure excerpts, atomic latest-log publication, preserved parent
  errors/statuses and strict evidence/checksum handling from the shared owner.
- Adopt the baseline's task-relevant read-only sibling inspection and asynchronous
  ordinary PR cadence. Enforced GitHub checks/reviews and explicit synchronous
  requests still apply; native host and release qualification remain separate.

## 0.67.3 - 2026-10-21

- Select the published Host, Build and Testkit 0.63.2 packages and add optional
  `ic-host-http` only to Dashboard host consumers. Keep request/client policy,
  status admission, JSON decoding and public error projection in Query; replace
  the response accumulation loop with Host's fallible bounded reader.
- Reprepare the selected Build/Testkit executables with
  `make install-release-tools install-testkit` before their offline release and
  installed-IC checks; this dependency update does not install executables.
- Preserve early declared-size refusal, whole-chunk observed lengths, zero/exact
  budgets, transport causes, redirects and the existing 30-second deadline. Do
  not retain partial failure bodies or preallocate from untrusted Content-Length.
  Project allocation failures into the existing body-read error category.
- Extend dependency-graph checks to exclude the HTTP reader from pure/Wasm and
  unrelated host profiles
  ([#93 — Adopt ic-host-http for bounded native JSON response reads](https://github.com/dragginzgame/ic-query/issues/93)).

## 0.67.0 - 2026-10-21

- **Breaking:** select published Host Artifacts, FS, Process, Text and Tools,
  Build and Testkit 0.63.0. Query's public certificate decode error carries Host
  Tools 0.63's `ParseError`, and certified ledger-tip authentication returns
  its `LedgerTip`. Consumers naming or exchanging these types must select
  `ic-host-tools = "0.63"` with the applicable features. Preserve byte limits,
  authentication, cache/report formats, external IC bytes and error categories.
- Enable `cli` explicitly when preparing or checking the lockfile-selected
  Build release editor and Testkit server command. Library dependencies leave
  `cli` disabled. Update installer
  fixtures alongside their real callers; re-run `make install-release-tools`
  and `make install-testkit` before their standalone offline checks.
- Testkit no longer owns Candid call helpers or benchmark ratio errors. Query
  already uses Platform codecs around raw PocketIC calls for required external
  Governance protocols and Wire for its own probe, so no fixture codec or
  transport/recovery translation is added. Keep the smoke runner's five-second
  TERM grace and bounded reaping policy.
- Select published Platform 0.6.0 and its matching entrypoint macros. Its
  Principal feature is included by Query's Candid, Agent and runtime selections;
  no consumer import or feature changes are required. Preserve external IC type
  identities, reply limits and the executor/ic0 instances. Host Tools and
  Testkit 0.63.0 now use Platform 0.6 too, retiring the resolved Platform 0.5.1
  package without overriding published requirements.
- Route shared snapshot loading through keyed admission without an unkeyed
  intermediate loader. Preserve missing-cache projection, bounded reads, schema,
  network, completeness and identity checks in their existing order. Converge
  page-fetch and attempt-checkpoint failures through one progress/error path
  while retaining checkpoint timing and incomplete-refresh behavior for NNS/SNS.
- Move the `futures` umbrella out of production dependencies. Collection keeps
  the same `futures-util` stream combinators and concurrent join macros directly;
  native fixture executors remain development-only. No package version changes
  are needed. The production CLI graph drops the umbrella package; Agent still
  requires Futures IO through its Reqwest blocking feature.
- Remove redundant direct Tokio activation from Dashboard, CloudEngine, CMC,
  certified IC state, ICRC and SNS features. Only Registry acquisition uses
  Tokio directly for retry delays; the library's runtime-builder feature is
  development-only. Agent and Reqwest retain their required transitive runtime,
  and the CLI still owns runtime construction. Enforce these direct-dependency
  exclusions in the existing graph checks without changing endpoint, deadline,
  retry or cancellation behavior.
- Replace the Governance smoke runner's hand-written grammar and help text with
  Clap and the CLI's existing command-tree policy. No arguments and explicit
  root help print the same complete help successfully; each operation also has
  local help. Invalid arguments still exit with status 1 before build or network
  effects. Retain validated principal spelling and non-UTF8 artifact paths.

```bash
cargo run -p ic-query-cli --example governance_smoke --locked --offline -- help inspect-wasm
```
