# 0.40 Changelog

## 0.40.1 - Unreleased

### Portable continuation accounting and release evidence

- Hard-cuts `NnsProposalCollectionState::proposals_fetched` and
  `NnsNeuronCollectionState::neurons_fetched`, including their public
  accessors, from target-width `usize` to fixed-width `u64`. Schema-1
  continuation JSON now has one numeric contract across native hosts and
  32-bit Wasm consumers; native-only refresh plumbing continues to derive its
  platform-local counters from the rows retained by that host.
- Records release dates for the tagged 0.38.0–0.40.0 lines. The 0.38 design now
  also states that the repository retains no receipt for its required manual
  mainnet canister smoke, without inferring whether that smoke was run.

## 0.40.0 - 2026-08-15

### Portable NNS public-neuron distribution analytics

- Adds `build_nns_neuron_distribution_report`, a synchronous pure projection
  over a valid, API-exhausted `NnsNeuronCollectionState` and the complete
  caller-retained public neuron rows accounted for by that state.
- Adds schema-1 `NnsNeuronDistributionReport` output with collection network,
  Governance canister, source and collector provenance, start/update times,
  admitted page/row counts, raw row retrieval-time range, and an explicit
  false point-in-time guarantee.
- Adds canonically raw-code-ordered state, optional visibility, and optional
  neuron-type rows. Each retains its native code or absence, typed
  classification, neuron count, and public effective-stake total; distinct
  unknown raw codes remain distinct.
- Adds total public effective stake plus reported/unreported row coverage and
  reported-only totals for optional staked maturity, deciding voting power,
  and potential voting power. Known-neuron metadata and Neurons' Fund join-
  timestamp presence are counted without inferring private or owner state.
- Reuses the continuation state's lifecycle/accounting validation and the
  public neuron row classification/order validator. Partial collections,
  mismatched row counts, malformed rows, and checked accounting overflow fail
  with typed `NnsNeuronDistributionError` values.
- Adds `validate_nns_neuron_distribution_report` and typed
  `NnsNeuronDistributionValidationError` failures for retained schema,
  identity, provenance, feasible collection page/row accounting, assurance,
  retrieval range, optional coverage, canonical ordering, raw classification,
  count, and stake invariants. Freshly built reports pass through the same
  validator before return.
- Adds a reusable text renderer with separate collection/coverage preamble,
  state, visibility, and neuron-type sections. JSON retains raw codes, raw
  values, optional coverage, timestamps, counts, and provenance.
- Keeps the builder, validator, and renderer available under
  `default-features = false` for native and Wasm callers. Adds no compatibility
  reader, crate, Cargo feature, dependency, network call, cache or stable-
  memory policy, or CLI surface.
