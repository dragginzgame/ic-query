# 0.82 release notes

## 0.82.0 - 2026-11-01

### ⚠️ Breaking

`SnsRewardCheckpointReport.summary: SnsRewardCheckpointSummary` owns the maturity
aggregates, permission and disbursement counts, auto-stake counts and policy
observations. Rust consumers update field access, for example from
`report.aggregate_maturity_e8s_equivalent` to
`report.summary.aggregate_maturity_e8s_equivalent`, and construct the summary record
in report literals. This is a pre-1.0 hard cut without compatibility accessors.

`SnsRewardCheckpointReport.canisters` and `SnsRewardDiffCheckpointRef.canisters`
carry `MainnetSnsCanisters`. Read Root, Governance, ledger, swap and index identities
through that record and supply it in struct literals. `SnsUpgradeReport.context`
and `SnsSnapshotRefreshReport.context` carry `SnsReportContext`, matching other
Governance report envelopes. Their identity and acquisition fields remain flat
in JSON; text output and schema-1 cache contents are unchanged.

The summary remains flattened into the existing top-level JSON fields. Schema 1,
strict unknown/duplicate/missing-field checks, raw checkpoint evidence and text
output are preserved. Restored checkpoints independently recompute and compare
the whole summary. Existing checkpoint files need no reset or recollection.

Platform 0.16.0 and Host Tools/Testkit 0.76.0 share one Platform identity and the
existing canonical Types 0.15.1 supplier. Align direct dependencies for public
certificate, ledger and runtime types and rebuild consumers. Platform now owns
certificate/hash-tree types; Query uses explicit conversions to native Agent
types for verification and state-tree reads. Host keeps strict bounded CBOR
decoding. Endpoint/root-key policy, freshness, byte budgets, original reply
evidence and external protocol bytes are unchanged.

The public Rust field change requires the next minor release. Package versions
and release execution remain maintainer-owned.

### ⬆️ Dependencies

Align the declared Host/Foundation requirements, including Build, to 0.73.4 and
Wire to 0.13.3, matching the already selected lockfile. Platform 0.16.0 and Host
Tools/Testkit 0.76.0 remain aligned. Wire's new fixed-byte-array representation is
opt-in; Query retains its existing field representations, frames and limits.
These requirement updates preserve the previously qualified dependency graph.

### 🧹 Cleanup

- Dashboard adapters share endpoint parsing and path-segment appending while
  retaining resource-specific query parameters, bounds and error projection.
- SNS lookup, complete refresh and cache-status parsers return report requests
  directly. Topology refresh does the same. Cache roots and clocks remain explicit
  at the CLI boundary; accepted arguments, defaults, help and output are unchanged.
