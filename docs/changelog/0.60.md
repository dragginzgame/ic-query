# 0.60 release notes

## 0.60.0 - 2026-10-17

- **Breaking:** Replace the neuron/proposal cache summary and status types with
  `nns::governance::NnsGovernanceCacheSummary` and
  `nns::governance::NnsGovernanceCacheStatusReport`. Both family status builders
  retain their names, cache validation and sidecar error policies. Use
  `nns_governance_cache_status_report_text` for either result; no family aliases
  or forwarding renderers remain.
- Status JSON identifies `collection` as `neurons` or `proposals`. Both summaries
  include Governance identity and point-in-time assurance. Invalid summaries
  retain refusal diagnostics and use empty timestamp/endpoint strings instead
  of display sentinels; they do not project unvalidated source values.
- Proposal cache-list reports retain the single expected collection's
  `refresh_attempt_path` and `latest_attempt` at report level, beside `collection`.
  These fields no longer repeat inside each cache summary. Status already keeps
  attempt evidence at report level. Update Rust literals and JSON consumers.
  List sidecar inspection remains best-effort; status inspection remains strict.
- Share summary and status projection plus human-facing status/attempt formatting
  under Governance collection ownership. Family loaders retain row, continuation,
  identity and completeness admission. These report changes remain schema 1;
  stored snapshots and sidecars are unchanged and require no reset or migration.
- **Breaking:** Native `IcrcBalanceRequest`, `IcrcAllowanceRequest`,
  `IcrcTransactionsRequest`, `IcrcArchivesRequest` and
  `IcrcAccountTransactionPageRequest` compose `ledger: IcrcLedgerRequest`.
  Their constructors take that scope before operation settings. Update direct
  field access, constructors and literals; no flat-field compatibility path remains.
  Retain request normalization, admission order, explicit index discovery and
  archive-follow policy. Clock-free account-cache identity and raw report JSON
  are unchanged.
- Derive CMC cycles from the existing validated XDR-report builder and render
  common rate lines once. Both public reports remain distinct; each collection
  performs one source call and preserves network refusal, certificate/witness
  evidence, provenance, integer arithmetic and text field ordering.
- Adapt explicit-output path resolution and Governance smoke process spawning to
  the selected Host signatures, preserving symlink budgets and the five-second
  TERM grace and bounded reap policy.

- **Breaking:** Address targeted SNS cache reads, cache status, cached neuron
  sorts and CLI proposal lists by root principal. Numeric selectors remain for
  live lookup and explicit refresh; numeric proposal-detail CLI calls use live
  lookup. Existing complete snapshots and sidecars stay schema 1 with no reset.
- Use canonical ICRC ledger account, metadata and allowance wire types. Account
  evidence now requires 32-byte subaccounts; preserve raw decimal/hex report JSON.
- Standardize Dashboard text on the complete provenance preamble already used by
  CloudEngine; JSON is unchanged.
- The SNS native feature now selects `icrc-ledger-types` for account and metadata
  records; the portable canister feature is unchanged. Remove matches for
  `SnsHostError::AmbiguousCacheId`, `AmbiguousRefreshAttemptId` and
  `MissingNeuronsCacheForId`; root-addressed cache operations no longer need
  these numeric-selector errors.

- Share CLI progress frames with published Host Text 0.23.1, preserving terminal
  admission, stderr ownership and non-TTY silence while escaping unsafe controls
  and clearing Unicode display columns correctly. [#70](https://github.com/dragginzgame/ic-query/issues/70).
- Align the Governance smoke harness with published IC Build 0.11 and Host 0.23,
  resolving the cleanup-policy type mismatch without changing TERM/reap policy.

- **Breaking:** SNS custom sources return `SnsNeuronDetail`, `SnsProposalRow`
  and vectors of existing neuron/proposal rows directly. Remove the five
  single-payload `MainnetSns*` result wrappers and update source implementations;
  the neuron page retains its cursor. Source validation, report JSON and stored
  snapshots remain unchanged.
- Custom `SnsNeuronSource` implementations return `SnsNeuronDetail` instead of
  `MainnetSnsNeuron`; `SnsProposalSource` returns `SnsProposalRow` instead of
  `MainnetSnsProposal`. `SnsNeuronsSource::fetch_sns_neurons` returns
  `Vec<SnsNeuronRow>` instead of `MainnetSnsNeurons`. Both proposal-list methods
  return `Vec<SnsProposalRow>` instead of `MainnetSnsProposals` or
  `MainnetSnsProposalPage`. Update imports, return signatures and construction
  without replacement aliases. The separate `MainnetSnsNeuronPage` still binds
  the source's native cursor to its returned rows.

- Fix test compilation with Testkit 0.50 by using Host Process HTTP readers
  directly and supplying explicit Candid reply budgets for the Governance probe.
  Preserve fixture deadlines, request-size limits and raw response behavior.
  [#72](https://github.com/dragginzgame/ic-query/pull/72).
