# 0.32 Changelog

## 0.32.0 - 2026-08-08

### Bounded replica release records

- Adds `icq ic replica-version list` for one explicitly bounded official
  Dashboard release page. The command defaults to 50 rows, caps requests at
  100, accepts an explicit offset and optional proposal-index ceiling, and
  never follows another page automatically.
- Adds `icq ic replica-version info <replica-version-id>` for one exact release
  record including the raw release-note summary and Dashboard-recorded Subnet
  rollout proposals.
- Preserves raw release ids, proposal ids, Unix-second execution timestamps,
  lifecycle status, titles, URLs, pagination totals, and Subnet rollout rows.
  JSON keeps the full exact summary; compact text truncates it safely.

```bash
icq ic replica-version list --limit 25
icq ic replica-version list --offset 25 --max-proposal-index 438 --json
icq ic replica-version info e3d101b22ae3fa02aca737f9fb96cc6c4ca83ac3
```

### Authority and bounds

- Both operations make exactly one live Dashboard request, use the shared
  8 MiB response limit, and never read or write a report cache.
- Reports retain `authority: official_ic_dashboard_api`, `certified: false`,
  and `point_in_time_guaranteed: false`. Release-election and rollout records
  are not presented as proof of the binary a Subnet currently runs.
- Builders reject invalid version ids and bounds before source calls, then
  validate echoed query/provenance, pagination accounting, descending release
  order, unique proposal rows, canonical Subnet principals, and exact
  info-target identity.

### Roadmap reconciliation

- Records the shipped 0.31 Registry/control-plane CloudEngine inventory and
  schema-1 hard cut in the current roadmap and command contract.
- Moves bounded replica release records into implemented Dashboard coverage;
  runtime-version evidence remains a separate gap.

### Downstream impact

| Surface | Change | Downstream action |
| --- | --- | --- |
| CLI | New `ic replica-version list|info` family | Use `list` for one page and reuse its resolved proposal-index ceiling for later explicit pages; use `info` for the full summary |
| Pure library | New replica-version requests, reports, rows, status, constants, and text renderers | Import them from `ic_query::ic` |
| Dashboard host | New `IcReplicaVersionSource` plus live/custom builders | Implement the focused source trait for alternate Dashboard-compatible authorities |
| Cache/schema | Live-only schema-1 reports; no persisted cache | None |
