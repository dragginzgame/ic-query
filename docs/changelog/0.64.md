# 0.64 release notes

## 0.64.1

### Fixed

- Include Query's selected `.tools/testkit-server` directory in failure archives.
  Retain Testkit-owned setup diagnostics, partial downloads and earlier attempts
  without parsing their internal layout. Missing directories do not prevent
  collecting common tool evidence; archived links are never followed. Tool
  versions, download policy and original setup failures are unchanged.

### Changed

- Retain Query's real Make include-boundary refusal and recursive selections,
  jobserver behavior, CI target order, input inventory, hooks and release recovery
  tests. Remove the overlapping execution-mode matrix and raw runner timing/log
  cases; Shared Tooling owns those generic implementation regressions. No public
  API, CLI behavior, snapshot or configured validation gate changes.

## 0.64.0 - 2026-10-19

### Breaking

- Select published Host Artifacts, FS, Process, Text and Tools 0.30.0.
  `CertificateVerificationError::Decode` now contains Host Tools 0.30's
  `certificate::ParseError`. Callers explicitly naming the payload must update
  their Host Tools dependency to 0.30 and rebuild. Decoder limits, CBOR bytes,
  error categories and authentication policy are unchanged.

- Hard-cut the owned Governance probe to Wire 0.4.9 frames with method ID 1,
  128-byte requests and 2 MiB replies. The entrypoint admits length before copying
  and traps invalid requests before report work. Both Testkit and Agent callers
  use matching frames. Required external Governance methods still use Candid.
  Rebuild/redeploy the probe and use the matching runner. Replace its DID metadata
  with `ic-query:protocol` from `probe-wire.json`; receipts keep schema 1 and now
  record `protocol_sha256` and original `.wire` response files. Retained evidence
  is not deleted or converted, and no older reader is kept. Report JSON is unchanged.

### Changed

- Explicitly select Host FS's `capability` feature for managed-cache operations.
  No local consumer needs its separate `temporary-file` backend; production
  graph checks refuse that feature. Capabilities remain excluded from portable
  and Wasm profiles. Testkit retains Host 0.29 transitively in its development
  graph until its owner publishes a compatible update.
- Complete Host Process 0.30 adoption with published IC Build 0.22. Its exposed
  cleanup policy now matches the harness. Preserve the five-second TERM grace,
  bounded reaping, deadlines and cancellation semantics. The release metadata
  editor now selects IC Build 0.22 and requires explicit tool preparation.
  [IC Build #9 — Qualify consumers against the exposed Host boundary](https://github.com/dragginzgame/ic-build/issues/9)
  retains consumer qualification.
- Adopt published Platform 0.2.1's maintained runtime and explicit-codec generator.
  Preserve the executor 2.0.0 and ic0 1.2.0 identities, original external Candid
  arguments, decoder limits, failure mapping and replicated call provenance.
  Production graph checks exclude the full CDK and its macros.
- Use published Testkit 0.55.2's raw-reply canister fixture with explicit update
  exports, method/name/reply allowances and a 1 MiB generated-module ceiling.
  Query retains its Candid reply catalog and report assertions. Remove the local
  WAT builder and Host's `wasm-text` feature, retiring `wat` and `wast` from the
  selected test graph while keeping binary Wasm inspection and encoding.
  This implements [#81 — Adopt Testkit raw reply fixtures](https://github.com/dragginzgame/ic-query/issues/81);
  installed-canister qualification remains separate from source adoption.
- Disable Futures' default executor in production and enable it only for native
  library tests. Preserve runtime-independent joins and bounded concurrent streams;
  production graph admission excludes `futures-executor`.
- Adopt published Host Tools 0.30's native agent builder and exact endpoint/byte
  ceiling binding. Live sources store Host's binding directly, removing Query's
  competing initialization and reuse implementation. Query retains strict URL
  admission, family error projection, response ceilings and the historical
  verification ingress-expiry override. No root keys are fetched by construction.
  IC-state and CloudEngine select Host's agent-only profile; their graph gates
  continue to exclude Candid parsing, independent certificate decoding and
  unrelated Host features. Portable and canister profiles remain free of Host Tools.
  See [#82 — Adopt Host native agent construction and endpoint binding](https://github.com/dragginzgame/ic-query/issues/82).
