# 0.56 release notes

## 0.56.0

### Breaking

- Replace local certificate/hash-tree parsing with the optional `ic-host-tools`
  certificate decoder. `CertificateVerificationError::Decode` now contains Host's
  `ParseError` instead of a Ciborium error. Callers using that concrete payload
  must adapt; the original CBOR cause remains available through the error chain.
  CBOR byte strings and certificate/delegation fields follow Host's strict format
  admission. Combined certificate/witness budgets, authentication before witness
  parsing, Agent trust-root policy, exact canister commitments and original reply
  evidence remain Query-owned. No older parser or compatibility surface remains.
  [#61 — Adopt Host certificate decoding](https://github.com/dragginzgame/ic-query/issues/61).

### Tooling

- Adopt Shared Tooling 0.15.0 through its reviewed snapshot exporter, preserving
  common host/Cargo/IC pins. Use the shared Perl rustdoc and type-layout checkers,
  their mechanical fixtures and explicit `crates` source selection. Keep Query's
  Cargo wrapper and debt baseline. Real compiler evidence establishes the same
  1,329 admitted identities, so adoption does not rewrite the baseline or add debt.
  [#55 — Adopt shared rustdoc debt checker](https://github.com/dragginzgame/ic-query/issues/55),
  [#57 — Adopt shared type-layout checker](https://github.com/dragginzgame/ic-query/issues/57).

- Complete the bounded IC Build resolver adoption: canonical Cargo metadata owns
  configured target decoding, and shared named-example admission selects the Wasm
  path. Before/after resolution guards semantic fingerprints and raw validation
  inputs; malformed/missing targets and concurrent changes fail before publication.
  Preserve the 600-second per-resolution deadline, interruption predicate, five-second
  TERM/reaping policy, original process evidence, source fingerprint framing,
  DID/build bytes and existing build executor. No artifact cache is introduced.
  [#53 — Finish bounded IC Build adoption](https://github.com/dragginzgame/ic-query/issues/53).

- Build the native Testkit executable before entering the managed PocketIC scope.
  Select both the 300-second hard lifetime and operation-idle lifetime explicitly;
  the earlier hard-only selection left PocketIC's 60-second idle default active
  while cold Cargo compilation was still running. Compilation failure stops
  before server launch; validation remains locked/offline and server setup explicit.
