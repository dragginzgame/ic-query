# 0.15 Changelog

Detailed release notes for the `0.15.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.15.0 - 2026-07-30

### Added

- Adds native public NNS neuron list and detail reports backed by Governance
  `get_neuron_index` and `get_neuron_info`.
- Adds `NnsNeuronSource` as a narrow custom-source capability implemented by
  the existing `LiveNnsSource`.
- Adds complete public neuron refresh, cache-preferred list/detail reads, and
  cache-only status reporting with typed refresh-attempt evidence.
- Adds public request, row, report, error, cache-path, refresh, and text
  rendering APIs under `ic_query::nns::neuron`.

  ```bash
  icq nns neuron list --limit 25
  icq nns neuron info 123456789 --verbose
  icq nns neuron refresh --page-size 300
  icq nns neuron cache status --format json
  ```

### Changed

- Centralizes proposal and neuron agent construction, Governance canister
  targeting, Candid transport, and response decoding in one internal NNS
  Governance query path while preserving each report family's public typed
  errors.
- Updates the 1.0 roadmap coverage estimate now that publicly readable NNS
  neuron state, stake, voting power, staked maturity, known-neuron metadata,
  and recent ballots are queryable.

### Guarantees

- Rejects non-mainnet neuron requests before agent construction.
- Preserves raw Governance state, visibility, neuron-type, and vote
  discriminants alongside readable labels.
- Validates strict ascending unique neuron ids, exclusive cursor progression,
  page bounds, exact detail ids, cache identity, and API exhaustion.
- Publishes a complete snapshot atomically under one refresh lock and keeps
  failure or capped-refresh evidence without replacing the prior snapshot.
- Records `point_in_time_guaranteed: false`: Governance supplies no stable
  collection version, so completing the page walk does not make its rows one
  instantaneous snapshot.
- Keeps private owner state and Dashboard analytics outside the report.
