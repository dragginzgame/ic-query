# 0.57 release notes

## 0.57.0 - 2026-10-15

### Breaking

- Adopt Host 0.19 across Query's direct Host dependencies.
  `CertificateVerificationError::Decode` now exposes Host 0.19's `ParseError`;
  callers naming or matching the concrete Host type must align their dependency.
  Certificate authentication, combined wire budgets, trust-root policy, witness
  commitments, report shapes and original evidence remain Query-owned.

### Tooling

- Adopt Shared Tooling 0.15.0 at its integrated, reviewed revision, retaining the
  existing common host, IC and Cargo tool pins. Delegate CI tool-evidence
  selection and archiving to its collector. Failed selections preserve their
  original status and output as diagnostics, retain safe local evidence and
  refuse to admit physical-store payloads from failed selector output.
  Keep Query's archive location, workflow execution and upload policy.

- Align IC Build 0.6 with Host 0.19 so the Governance harness exchanges one
  cleanup-policy type. Preserve explicit command limits, five-second TERM grace,
  bounded reaping, process evidence and publication policy. Canonicalize newly
  created fixture roots before private-parent preparation, supporting temporary
  directory aliases without weakening Host's symlink refusal.

- Use published `ic-testkit-candid 0.45` for native and Wasm reply decoding.
  Query retains proportional decoding quotas, bounded skipping, type/header
  ceilings, the 8 MiB transport limit and its original Candid error projection.
  The smoke harness retains exact-one-text admission, its 2 MiB reply ceiling
  and private create-new publication of original replies before decoding.
  The standalone package depends only on Candid and Serde, keeping Testkit,
  PocketIC and WAT out of normal consumer graphs.
  [#58 — Adopt bounded Candid reply decoding](https://github.com/dragginzgame/ic-query/issues/58).

- Replace the final fixed-JSON Python fixture with a shell literal. Current
  tooling no longer requires Python; setup documentation reflects the separate
  deterministic Testkit scenario and the selected Testkit 0.45 development tools.
