# 0.31 Changelog

## 0.31.1 - 2026-08-08

### Registry-backed CloudEngine inventory

- Adds `icq cloud-engine list`, which loads the complete
  Registry-classified CloudEngine Subnet inventory through the existing
  missing-or-invalid Subnet Catalog read policy and then attempts one exact
  public control-plane operator-binding lookup per row, capped at 100 rows.
- Preserves the two authorities independently: Registry version, assurance,
  source endpoints, catalog digest/cache disposition, and classification
  provenance are not merged with the control-plane endpoint, timestamp, or
  uncertified consistency limits.
- Reports `resolved`, successful `absent`, and per-row `failed` binding
  outcomes separately. A control-plane failure does not discard the Registry
  snapshot, and `cloud-engine info` remains the explicit operation for owner,
  administrator, Caffeine, and domain detail calls.

```bash
icq --network ic cloud-engine list
icq --network ic cloud-engine list --json
```

### Pre-1.0 schema hard cut

- Normalizes every remaining active schema identifier to `1`: the certified
  Registry version and delta reports, certified Registry archive manifest,
  ordinary Subnet Catalog cache, and Subnet Catalog list, info, and refresh
  reports.
- Keeps the current data shapes and exact validation boundaries. Existing
  ordinary catalog caches and certified Registry archive manifests carrying
  another schema identifier are rejected without a fallback reader, migration,
  or automatic rewrite; callers must explicitly refresh or bootstrap them.
- Updates public examples, fixtures, and current documentation to describe the
  schema-1 contracts. Adds a CI guard that rejects active Rust schema constants
  above `1`; historical release notes remain unchanged.

### Release flow

- Allows the detailed target-version heading to retain its `Unreleased`
  suffix during `make patch`, `make minor`, and `make major`. The changelog
  gate continues to require a committed matching root release-ledger entry, a
  committed matching detailed heading, and current dependency-example minor
  versions.

### Downstream impact

| Surface | Change | Downstream action |
| --- | --- | --- |
| CLI | New `cloud-engine list` operation | Use it for Registry inventory plus bounded operator bindings; use `info` for one operator's public details |
| Native library | New list builder requires `cloud-engine-host` and `subnet-catalog-host` | Enable both focused features, or use `host` |
| Registry reports | Current schema identifiers are now 1 | Rebuild constructed report values with schema 1 |
| Certified Registry archive | Manifest and retained delta identifiers are now 1 | Explicitly bootstrap archives emitted with another identifier |
| Ordinary Subnet Catalog | Cache and list/info/refresh report identifiers are now 1 | Explicitly refresh unsupported cached content under the selected read policy |

## 0.31.0 - 2026-08-08

### Top-level CloudEngine reports

- Adds `icq cloud-engine info <subnet-id>` for an exact mainnet
  Subnet-to-operator resolution plus bounded public operator details. An
  absent binding is a visible one-call result without a Subnet-existence claim;
  a returned operator uses exactly five native query calls.
- Adds `icq cloud-engine prices` for the public network fee and up to 1,000
  marketplace prices in exactly two native query calls.
- Both commands are live-only, mainnet-only, uncached, and accept an explicit
  `--source-endpoint`. Text is human-facing; JSON preserves raw principals,
  arbitrary-precision decimal cycle amounts, row identities, nanosecond
  timestamps, query counts, and source provenance.

```bash
icq --network ic cloud-engine info 2nl67-oqoc5-cmocj-otlhq-kr2kr-53hov-drrds-7ihcs-fhomv-2eyvu-6qe
icq --network ic cloud-engine prices --json
```

### Authority and bounds

- Pins the ICP CLI 1.3.0 Subnet-to-operator resolver contract and mainnet
  canister `q6cfj-fyaaa-aaaar-qb77q-cai`, plus the queried public
  operator/marketplace response shapes, behind typed Candid wire DTOs.
- Reports state `authority: cloud_engine_control_plane_canister`,
  `certified: false`, and `point_in_time_guaranteed: false`; sequential calls
  do not inherit a Registry version or claim one snapshot.
- Validates exact query budgets, source-request provenance, canonical
  principals and marketplace identities, unique bounded rows/domains, finite
  network fees, exact decimal cycle amounts, and positive update timestamps.

### Focused library surface

- Adds pure `ic_query::cloud_engine` models and text renderers plus host-only
  source traits and builders.
- Adds `cloud-engine-host` for the native adapter without direct cache,
  Registry, REST, certificate-decoding, or hashing dependencies. The complete
  `host` feature includes it.
- Adds fixture-backed unit, public-API, CLI-help, dependency-boundary, Candid
  round-trip, JSON, and text tests. No live mainnet request is required by the
  test suite.

### Downstream impact

| Surface | Change | Downstream action |
| --- | --- | --- |
| CLI | New top-level `cloud-engine` family | Use `info` for one Subnet or `prices` for the bounded marketplace |
| Pure library | New report DTOs and renderers | Import from `ic_query::cloud_engine` |
| Native library | New focused `cloud-engine-host` feature | Select it when CloudEngine is the only required live authority |
