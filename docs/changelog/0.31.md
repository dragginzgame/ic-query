# 0.31 Changelog

## 0.31.0 - Unreleased

### Top-level CloudEngine reports

- Adds `icq cloud-engine info <subnet-id>` for an exact mainnet
  Subnet-to-operator resolution plus bounded public operator details. An
  absent binding is a visible one-call result without a Subnet-existence claim;
  a returned operator uses exactly five native query calls.
- Adds `icq cloud-engine prices` for the public network fee and up to 1,000
  marketplace prices in exactly two native query calls.
- Both commands are live-only, mainnet-only, uncached, and accept an explicit
  `--source-endpoint`. Text is human-facing; JSON preserves raw principals,
  arbitrary-precision decimal cycle amounts, row identities, nanosecond
  timestamps, query counts, and source provenance.

```bash
icq --network ic cloud-engine info 2nl67-oqoc5-cmocj-otlhq-kr2kr-53hov-drrds-7ihcs-fhomv-2eyvu-6qe
icq --network ic cloud-engine prices --json
```

### Authority and bounds

- Pins the ICP CLI 1.3.0 Subnet-to-operator resolver contract and mainnet
  canister `q6cfj-fyaaa-aaaar-qb77q-cai`, plus the queried public
  operator/marketplace response shapes, behind typed Candid wire DTOs.
- Reports state `authority: cloud_engine_control_plane_canister`,
  `certified: false`, and `point_in_time_guaranteed: false`; sequential calls
  do not inherit a Registry version or claim one snapshot.
- Validates exact query budgets, source-request provenance, canonical
  principals and marketplace identities, unique bounded rows/domains, finite
  network fees, exact decimal cycle amounts, and positive update timestamps.

### Focused library surface

- Adds pure `ic_query::cloud_engine` models and text renderers plus host-only
  source traits and builders.
- Adds `cloud-engine-host` for the native adapter without direct cache,
  Registry, REST, certificate-decoding, or hashing dependencies. The complete
  `host` feature includes it.
- Adds fixture-backed unit, public-API, CLI-help, dependency-boundary, Candid
  round-trip, JSON, and text tests. No live mainnet request is required by the
  test suite.

### Downstream impact

| Surface | Change | Downstream action |
| --- | --- | --- |
| CLI | New top-level `cloud-engine` family | Use `info` for one Subnet or `prices` for the bounded marketplace |
| Pure library | New report DTOs and renderers | Import from `ic_query::cloud_engine` |
| Native library | New focused `cloud-engine-host` feature | Select it when CloudEngine is the only required live authority |
| Cache/schema | No cache; report schema starts at 1 | None |
