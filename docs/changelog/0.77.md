# 0.77 release notes

## 0.77.0

### ⚠️ Breaking

- Adopt published Platform 0.9.1 for Query's protocol types and canister runtime.
  Public ledger types now have Platform 0.9 identity, including the
  `ICRC3DataCertificate` returned by custom `IcrcTipCertificateSource`
  implementations. External Candid, Agent and certificate identities remain
  upstream; wire bytes, commands and report/cache schemas remain unchanged.
- Select Platform's embedded IC0 and executor for the canister adapter and typed
  Governance probe. Runtime handles now have Platform identity. Require one
  Platform runtime owner in the Wasm graph, retaining caller-owned scheduling,
  quotas, retry policy and error projection.

### 🧭 Migration Notes

- Update direct Platform dependencies that supply Query's ledger types to 0.9.
  Rebuild all canister runtime consumers against that line, including timer
  libraries when used. The runtime-feature singleton guard rejects combining
  Platform's executor with another runtime owner.
  No handle conversions or compatibility wrappers are provided.
- Released Host/Testkit 0.70.5 retain Platform 0.8 for their own native interfaces.
  Host-owned certificate errors and ledger evidence types keep their published
  Tooling identities. This separate native selection does not introduce another
  executor into Query's canister graph.

### 🔧 Changed

- Raise workspace minimums to published Host, Build and Testkit 0.70.5, Wire
  0.7.25 and Metrics 0.18.1. Metrics adds validated transport for summaries and
  fixed-bound histograms; Query retains its measurement arithmetic and native-only
  metadata boundary. Rust 1.91 support remains unchanged.
- Adopt Platform 0.9.1's optional runtime guard package. Require it once in the
  canister graph and exclude it from portable and native-only Query selections;
  native facades can coexist with an unrelated registry executor. Runtime code,
  public APIs and external bytes retain the Platform 0.9 contract. Metrics 0.18.1
  aligns its native metadata dependency with the selected Wire 0.7.25.
- Adopt Shared Tooling 0.27.11 at reviewed revision
  `62edfbd43087a718bf0283e9040676a49211976d` through its canonical snapshot exporter.
  Consume the validation checkpoint companion and optional structured Cargo
  graph observations while preserving Query's local CI and release adapters.
  Review lint allowances and module layout against the updated guidance; the
  publication adapter remains opt-in and Query keeps its existing implementation.
