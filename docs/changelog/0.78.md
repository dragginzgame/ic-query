# 0.78 release notes

## 0.78.0

### ⚠️ Breaking

- Adopt published Platform 0.11.1 for Query's public ledger types and canister
  runtime. Custom `IcrcTipCertificateSource` implementations now return its
  `ICRC3DataCertificate`. Rebuild every canister runtime consumer against Platform
  0.11, including timer libraries when used, with one executor owner.
- Adopt the coordinated Host, Build and Testkit 0.72.0 packages. Public
  certificate parse errors and ledger evidence values now have Host Tools 0.72
  identity; callers naming those types must update direct `ic-host-tools`
  dependencies. External Agent, Candid and certificate identities remain shared.

### 🧭 Migration Notes

- Align direct Platform dependencies on 0.11 and Wire dependencies on 0.10 when
  exchanging their Rust types. Host/Testkit and Query now share one Platform
  supplier for Registry principals and ledger values; Metrics metadata and probe
  codecs share one Wire supplier. Native facades exclude the executor guard;
  Query's canister graph selects one Platform 0.11 runtime and guard.
- Applications using Platform's retired `wire-schema` feature must select Wire's
  `platform-types` integration instead. Query uses the core codec and ordinary
  Serde reports without selecting optional Platform schemas or endpoint macros.
- Prepare the newly selected Build metadata editor and Testkit executable through
  Query's existing setup targets before their offline admission. Rust 1.91,
  protocol frames, admission budgets, commands and report/cache schemas remain
  unchanged; no persisted-data migration is required.

### 🔧 Changed

- Adopt IC Wire 0.10.0 for the Governance probe, native smoke harness and Testkit
  fixtures. Metrics 0.21.0 uses the same Wire version for native metadata;
  portable and canister library graphs continue excluding Wire. Measurement and
  percentage arithmetic, Serde layouts and protocol frames retain their contracts.
- Keep Governance calls on Platform's raw CDK transport. Platform also owns
  prepared one-shot calls through `ic_platform::call`; Query's transport policy,
  bounded decoding, trust roots and error projection retain their existing owners.
