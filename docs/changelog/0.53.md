# 0.53 release notes

## 0.53.0 - 2026-10-10

- Adopts committed Shared Tooling 0.2.13 at
  `5864f468d39f8f9d1bd26fca1afe0e20f25f1b5e` through the canonical exporter,
  retaining 77 files and the separately pinned engineering baseline. Shared
  admission owns Make execution guards and checks retained `MFLAGS` independently
  of replaced `MAKEFLAGS`; Query's supplementary parser is removed. Parallel
  and recursive execution retain their contracts.
  [Shared #30](https://github.com/dragginzgame/shared-tooling/issues/30).
- Snapshot verification rejects LF/CR in supplied and resolved directory paths,
  including aliases, ancestors and custom-manifest parents, before trimming can
  select another checkout. Ordinary spaces and relative physical aliases remain
  supported under `CDPATH`. Existing artifacts remain intact; affected operational
  directories require an explicit rename. Producer distribution fixtures remain
  upstream rather than expanding consumer CI.
  [Shared #95](https://github.com/dragginzgame/shared-tooling/issues/95).
- Selects published Host artifacts/filesystem/process 0.11.0 from
  `1d768c80a5bb87e3330a6b7bacfdfc543063968f`, changing only their three lockfile
  versions and checksums. Governance smoke adopts `OutputLimit::Terminate` and
  explicit finite deadlines. Complete command bytes remain available for parsing;
  commands do not truncate structured output. TERM grace, bounded reaping,
  cancellation, text admission and explicit background handoff remain local policy.
  Cleanup errors remain typed through `CleanupError`, separately from the original
  process failure. Receipt `command_cleanup_errors` entries now use Host's complete
  cleanup-attempt display instead of Query's per-stage string projection. Receipts
  remain schema 1; readers treating diagnostic strings as structured fields must
  update together. Existing receipts need no reset or migration, and no older
  process API or dual renderer is retained.
  [#38](https://github.com/dragginzgame/ic-query/issues/38).
  [Host #46](https://github.com/dragginzgame/ic-host-tooling/issues/46).
- Durable pathname publication refuses trailing `/` and `/.`, including repeated
  directory suffixes, before parent creation or staging. Smoke receipt regression
  preserves original bytes, directory entries and typed pre-publication failure.
  The same shared admission protects Wasm output paths; descriptor-relative cache
  publication and public Query report formats retain their contracts.
  [Host #44](https://github.com/dragginzgame/ic-host-tooling/issues/44).
- Adds narrow `install-format-tools` setup through the existing shared selected
  installer; `install-dev` reuses it. Formatting requires the exact versioned
  local receipt and executable bytes before probing cargo-sort or rustfmt. Global
  or optional-bundle installations no longer satisfy that selection. Existing
  selected installations remain usable; other installations and failed attempts
  remain available for inspection. A caller using only a global formatter must
  explicitly prepare the selected local installation before continuing.
- Standard release preflight prepares that installation after clean-source,
  candidate/notes admission and locked source fetching, then checks it offline.
  Explicit offline settings and setup/admission failures remain authoritative.
  Source identity and candidate agreement are rechecked after preparation;
  changed selections stop the attempt before tool admission.
  Saved-evidence recovery bypasses fetching and setup against interrupted metadata.
  The sequential CI roster checks formatter admission before expensive dependent
  work, including under parallel Make. Ordinary formatting and CI never install
  tools. No broad tool bundle or new installer is introduced.
  [#35](https://github.com/dragginzgame/ic-query/issues/35).
  [Shared #96](https://github.com/dragginzgame/shared-tooling/issues/96).
- Repairs the complete release-guard fixture's formatter dependencies. The
  fixture uses the real Make recipes and offline checker with simulated
  installation, verifies preparation before validation, and refuses setup or
  admission failures before version preparation. No real installation or
  release effects occur in these fixtures.
  [#35](https://github.com/dragginzgame/ic-query/issues/35).

```bash
make install-format-tools
make format-tools-check
```
