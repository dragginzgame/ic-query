# 0.13 Changelog

Detailed release notes for the breaking `0.13.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.13.0 - 2026-07-29

### Changed

- Makes SNS governance commands consistent singular entity families:
  `icq sns proposal list|info|refresh|cache` and
  `icq sns neuron list|refresh|cache`.
- Separates generic ICRC commands by query scope:
  `icq icrc ledger` owns capabilities, token metadata, index discovery,
  transactions, block types, archives, and tip certificates, while
  `icq icrc account` owns balance and allowance queries.
- Renames the public NNS proposal
  `NnsProposalHostError::LocalNetworkUnsupported` variant to
  `UnsupportedNetwork { network }`, retaining the rejected network identity
  consistently with the other NNS report families.
- Updates command help, cache refresh hints, the README, the SNS proposal-cache
  design, and the 1.0 roadmap to describe the current hierarchy. Report
  models, JSON shapes, cache keys, cache schemas, and collection behavior are
  unchanged.

  ```bash
  icq sns proposal list 1 --status open
  icq sns proposal info 1 387 --ballots
  icq sns proposal refresh 1
  icq sns proposal cache status 1
  icq sns neuron list 1 --sort stake
  icq sns neuron refresh 1
  icq icrc ledger token ryjl3-tyaaa-aaaaa-aaaba-cai
  icq icrc ledger transactions ryjl3-tyaaa-aaaaa-aaaba-cai --limit 25
  icq icrc account balance ryjl3-tyaaa-aaaaa-aaaba-cai aaaaa-aa
  icq icrc account allowance ryjl3-tyaaa-aaaaa-aaaba-cai aaaaa-aa aaaaa-aa
  ```

### Removed

- Removes the direct `icq sns proposal <sns> <proposal-id>`,
  `icq sns proposals ...`, and `icq sns neurons ...` command forms.
- Removes the direct top-level ICRC leaf forms such as
  `icq icrc transactions ...` and `icq icrc balance ...`.
- Removes the optional passthrough dispatch flow that existed only to support
  the replaced SNS direct-list grammar. No CLI aliases, fallback parsers,
  deprecated wrappers, or unimplemented command placeholders are retained.
