# 0.17 Changelog

Detailed release notes for the breaking `0.17.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## 0.17.1 - 2026-07-30

### Fixed

- Validates live source endpoints as HTTP(S) URLs before constructing
  `ic-agent`. Malformed endpoint text now returns the owning typed
  `AgentBuild` error across ICRC, Registry, NNS Governance, and SNS paths
  instead of reaching an infallible parser path.
- Applies the global mainnet network option at the NNS/SNS family boundary
  instead of maintaining a drifting leaf-command allowlist. This fixes
  forwarding for NNS Governance, NNS neuron, and SNS canister commands:

  ```bash
  icq --network ic nns governance economics
  icq --network ic nns neuron list --limit 25
  icq --network ic sns canister list 1
  ```

- Treats multiple SNS Root health summaries for one inventory canister as
  ambiguous evidence. The inventory row retains no selected status and carries
  a typed `duplicate_summary` gap rather than choosing the first response row.

### Changed

- Validates custom ICRC account-transaction pages against the requested
  explicit index, page limit, canonical cursors, and unique newest-first
  transaction ordering.
- Validates custom SNS-W discovery results against the source request,
  canonical and unique deployed-SNS identities, and expected SNS-W canister.
  SNS Root inventory results must also preserve the exact native method and
  call contract, `update_canister_list = false`, canonical principals and raw
  numeric fields, internally consistent health fields, and the absence of a
  point-in-time guarantee.
- Validates NNS Registry version source provenance against the requested
  network, Registry canister, endpoint, timestamp, and collector before report
  projection.
- Makes complete snapshot loading current-shape strict. Complete NNS
  Governance, SNS Governance, and ICRC index caches reject unknown or duplicate
  top-level fields. Proposal, neuron, and account-history caches reject a true
  point-in-time claim where the underlying paginated API exposes no snapshot
  version.

### Compatibility

- Adds typed `IcrcAccountTransactionError::InvalidPage`,
  `SnsHostError::InvalidSourceData`, and
  `NnsRegistryHostError::SourceMismatch` variants. Exhaustive downstream error
  matches must handle the new variants.
- This is a pre-1.0 hard cut. Invalid custom-source results and cache files
  containing extra top-level fields are rejected without aliases, fallback
  readers, or migration. Refresh an invalid cache using the owning explicit
  refresh command.
- Does not add commands, options, cache identities, live mutation behavior, or
  library process output.

## 0.17.0 - 2026-07-30

### Added

- Adds a live SNS Root canister inventory and operational-health report:

  ```bash
  icq sns canister list 1
  icq sns canister list 23ten-uaaaa-aaaaq-aabia-cai --format json
  ```

- Adds public `SnsCanisterReport`, row, native role/status, and typed gap DTOs,
  plus `build_sns_canister_report`, custom-source construction, and text
  rendering.
- Adds `SnsCanisterSource` as one focused capability implemented by the
  existing `LiveSnsSource`.

### Changed

- Adds network identity to the shared `SnsSourceRequest`. This is a breaking
  pre-1.0 hard cut to the public constructor and struct shape; there is no
  compatibility constructor or alias.
- Enforces the mainnet-only contract inside direct built-in SNS source calls
  before agent construction, rather than relying only on report-builder and
  CLI validation.
- Updates the SNS roadmap baseline to include native Root inventory, running
  module hashes, and operational health.

### Guarantees

- Uses Root's `list_sns_canisters` query as the membership authority for Root,
  Governance, Ledger, Swap, Index, Archive, Dapp, and Extension canisters.
- Calls Root's `get_sns_canisters_summary` ingress method with
  `update_canister_list = false`. The report never asks Root to poll Ledger or
  update its stored archive inventory.
- Preserves native role and `running | stopping | stopped` terminology, full
  module hashes, raw decimal cycles and memory values, idle cycle burn, and
  canonical controllers.
- Canonically orders role/principal rows, rejects duplicate inventory
  canisters, and retains missing ids, missing status, mismatches,
  summary-only canisters, duplicate summaries, and unsupported Extension
  health as typed gaps.
- States `point_in_time_guaranteed: false` because the inventory query and
  health ingress are sequential current-state reads without a shared Root
  version.
- Keeps the report live-only. It does not read, write, or invalidate SNS
  proposal or neuron caches and the library emits no process output.

### Scope

- Running version evidence is the current per-canister module hash. This slice
  does not compare those hashes with blessed SNS-W upgrade paths.
- This slice does not add swap lifecycle, treasury, aggregate analytics,
  direct management-canister calls, or mutation behavior.
