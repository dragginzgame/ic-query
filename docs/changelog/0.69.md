# 0.69 release notes

## 0.69.0

- **Breaking:** remove Query's implicit dependency-named `ic-host-tools` Cargo
  feature without an alias. Consumers must choose a supported capability such
  as `certificate-host`, `ledger-evidence-host`, a focused reporting feature,
  or the reporting `host` union according to the APIs they need.
- Activate the optional Host Tools dependency explicitly through Cargo's `dep:`
  syntax. Existing capability forwarding still selects the same Host features;
  this does not remove the dependency or change certificate policy,
  report/cache formats, or portable/canister dependency exclusions.
- **Breaking:** select published Host Artifacts, FS, HTTP, Process, Text and Tools,
  Build and Testkit 0.65.0. Consumers naming Host types exposed by Query must
  align their Host dependencies to 0.65, including the certificate decoder's
  parse error and authenticated ledger-tip return type.
- Select Platform 0.6.9, Wire 0.6.5 and Metrics 0.15.6. Platform's
  Rust 1.91 minimum matches Query's existing floor. Keep the published native
  Agent, Candid and canister runtime interfaces behind Platform.
- Retain the probe's native Serde/Postcard frames, raw evidence and explicit
  budgets. Platform's optional Wire metadata and Testkit's held/cycle-accepting
  reply fixtures remain unselected; existing Governance replies keep their
  non-accepting behavior.
- Query already sends native Serde frames directly, so Testkit's retirement of
  finite Wire call helpers requires no probe protocol or caller-code migration.
- Refresh the canonical Shared Tooling snapshot to 0.26.7 at
  `3e8d7cd3e7e9b7b79a5e800c30daf0be2710dab0`, retaining Query's existing
  entrypoints and executable pins and selecting the new CI/release integrity
  audit guide. Setup may wait briefly for an admitted shared
  Cargo-tool slot and rechecks inputs before reuse; offline admission remains
  immediate. Retain previous tool generations and failure evidence.
- Prepare Build's release metadata editor and Testkit's server through
  `make install-release-tools install-testkit`. Both executables require `cli`;
  library dependencies retain their existing feature selections. No Query
  package version, release ref or deployment is changed by dependency adoption.
