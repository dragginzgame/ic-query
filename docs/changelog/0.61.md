# 0.61 release notes

## 0.61.0

- **Breaking:** `SnsTokenReport` and `MainnetSnsToken` use the canonical
  `icrc::IcrcTokenStandardRow` and `icrc::IcrcTokenMetadataRow`. Replace imports
  and literals of `SnsTokenStandardRow` and `SnsTokenMetadataRow`; their exports
  are removed without compatibility aliases. ICRC callers retain their existing
  public row names. Ledger fetching and both report families share those rows
  directly, removing field-copy conversions and intermediate vector collections.
- **Breaking:** Custom `IcrcBlockTypesSource::fetch_block_types` implementations
  return `Vec<IcrcBlockTypeRow>` and `IcrcArchivesSource::fetch_archives` returns
  `Vec<IcrcArchiveRow>`. Remove construction of `IcrcBlockTypesData` and
  `IcrcArchivesData`; those wrappers are removed. Requests, archive cursors,
  provenance, fetch order and report row ordering remain unchanged.
- **Breaking:** `MainnetSnsToken` composes `token: icrc::IcrcTokenData` beside
  its ledger index and discovery error. Update custom-source literals and field
  access. Ledger fetching returns that same payload directly; ICRC source
  implementations retain their existing `IcrcTokenData` result. The payload is
  portable and available without a host feature, with no native dependencies.
- ICRC-106 discovery has one typed query owner under shared ledger mechanics.
  SNS metadata retains transport/application discovery failures as evidence;
  account-history collection keeps typed refusal and ledger/index binding checks.
- **Breaking:** `CmcCyclesReport` composes `xdr: CmcXdrReport` beside derived
  cycle fields. Use `report.xdr.context`, `report.xdr.rate` and
  `report.xdr.certification` in Rust. Serde flattens the XDR report, preserving
  the existing JSON field names and values. Text ordering, a single source call,
  certificate admission and exact cycle arithmetic remain unchanged.
- **Breaking:** NNS `NnsNeuronRow` removes `state_text`, `visibility_text` and
  `neuron_type_text`; `NnsNeuronBallotRow` removes `vote_text`. The three neuron
  distribution bucket types remove their corresponding classification fields.
  Rust and JSON consumers use the retained raw codes. Derive labels through
  `NnsNeuronState::from_code`, `NnsNeuronVisibility::from_code`,
  `NnsNeuronType::from_code` and `NnsGovernanceVote::from_code` when needed.
  Native and canister sources preserve unknown codes and absent optional codes.
- Neuron rows, ballots and distribution buckets reject unknown JSON fields.
  Existing neuron snapshots with the replaced row shape require an explicit
  `icq nns neuron refresh`. Preserve retained evidence as needed before that
  authorized replacement. Cache-only reads refuse it without changing bytes;
  no migration, fallback reader or automatic reset is supplied. Successful
  refresh atomically publishes a complete new snapshot; failed refresh preserves
  the existing snapshot. Report, snapshot and sidecar schemas remain 1; continuation,
  ordering, page/row accounting, totals and provenance checks remain in force.
- ICRC-106 replies use standard Rust `Result` and supported-standard replies
  decode directly into `IcrcTokenStandardRow`. Remove duplicate private wire
  models while preserving native Candid variants, record fields and query errors.
- SNS version evidence has one hash-validation owner beside `SnsVersion`.
  Upgrade reports continue to require nonempty lowercase even-length hex;
  reward checkpoints continue to require exactly 32-byte hashes. Both source
  admission and serialized checkpoint admission keep their validation and
  caller-specific errors.
- ICRC/SNS token metadata JSON and CMC JSON retain their existing shapes and
  values. Metadata numbers remain exact decimal strings and blobs remain
  lowercase hex. Human-facing neuron and distribution labels remain unchanged.

- Development and canister tooling select ICP CLI 1.7.0 with official archive
  digests for Linux x86-64 and both macOS architectures. Run
  `make install-ic-tools` to activate the selected set before offline checks.
  The explicit consumer catalog keeps the reviewed Shared Tooling snapshot
  intact and retains the existing managed-runtime pin and other IC tool versions.

- Fix native host builds after the Host 0.25 adoption by selecting its current
  descriptor-relative durable writer. Retain replace mode, private staging,
  the admitted parent descriptor and existing publication/cleanup errors.
- Update the Governance canister fixture for Testkit 0.51’s installation
  specification and explicit anonymous caller. Probe initialization, funding,
  report reply limits and assertions remain unchanged.

- **Breaking:** NNS proposal rows, ballots and activity count buckets retain
  raw topic, decision, reward and vote codes without stored classifications.
  Renderers and sorts derive the same human labels from those codes, including
  unknown vote values. Remove classification-field construction and handling of
  classification-mismatch error variants from custom integrations. Preserve
  existing proposal cache evidence before explicitly refreshing it with
  `icq nns proposal refresh`; cache-only reads reject the replaced shape.
  Activity reports also replace their schema-1 row shape in place. There are
  no fallback readers or automatic data conversions.
- **Breaking:** `IcrcTipCertificateSource::fetch_tip_certificate` returns
  `Option<icrc_ledger_types::icrc3::blocks::ICRC3DataCertificate>`. Custom
  sources return the original certificate/hash-tree byte pair after their
  verification, or `None` when absent. The report builder computes hex and byte
  lengths; capability-only probes retain bytes without formatting them.
  Authentication, limits and report JSON fields remain unchanged.
- **Breaking:** `MainnetSns`, `SnsListRow` and `SnsInfoReport` embed
  `canisters: MainnetSnsCanisters`. Update custom literals and access each
  principal through `canisters`. The existing identity type is now portable;
  its fields remain flat in report and catalog JSON. Discovery, exact-target
  enrichment, principal validation and persisted schema-1 shapes are retained.

- Include the repository’s MIT license text and existing copyright notice in
  both published crate packages, matching their inherited license declarations.
  [PR #60 — Include MIT license text in published packages](https://github.com/dragginzgame/ic-query/pull/60).
