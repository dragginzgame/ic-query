## 0.16.0 - 2026-07-30

### Added

- Adds four direct native NNS Governance reports:

  ```bash
  icq nns governance economics
  icq nns governance metrics --format json
  icq nns governance reward-event
  icq nns governance maturity-modulation
  ```

- Adds public economics, cached-metrics, neuron-subset metrics, metric-bucket,
  latest reward-event, maturity-modulation, report-context, and report DTOs
  under `ic_query::nns::governance`.
- Adds `NnsGovernanceSource` as one focused custom-source capability
  implemented by the existing `LiveNnsSource`.
- Adds live builders, custom-source builders, text renderers,
  `NnsGovernanceHostError`, and
  `DEFAULT_NNS_GOVERNANCE_SOURCE_ENDPOINT`.
- Adds `NnsSourceRequest::from_unix_secs` so native callers can construct the
  shared NNS source provenance without duplicating timestamp formatting.

### Guarantees

- Queries native Governance
  `get_network_economics_parameters`, `get_metrics`,
  `get_latest_reward_event`, and `get_maturity_modulation` methods.
- Preserves current native Governance fields and terminology. Nested optional
  percentage and decimal wrappers remain distinguishable, maturity modulation
  remains a signed permyriad value, settled proposals retain their native id
  records, and metric/subset values remain raw.
- Projects unlabeled Candid metric bucket pairs to named `key`/`value` JSON
  rows without changing their numeric values.
- Rejects a non-finite floating-point metric bucket as a typed invalid-metrics
  response instead of allowing JSON serialization to replace it with `null`.
- Records the network, Governance canister, source endpoint, collection
  timestamp, and collector in every report. The shared Rust context is
  flattened at the JSON report root.
- Rejects a non-`ic` network in both report builders and direct live-source
  methods before source invocation or agent construction.
- Preserves typed Governance application errors from `get_metrics` separately
  from agent, Candid, and runtime failures.
- Performs exactly one Governance query per report. Native payload timestamps
  remain separate from the report collection timestamp, and the reports do
  not inherit Registry versions or claim certification.
- Keeps these bounded point-value reports live-only. They do not read, write,
  invalidate, or otherwise alter the complete proposal and neuron caches.

### Scope

- `reward-event` reports the latest voting reward event, not complete reward
  history.
- This slice does not add delegation/followee state, authenticated neuron
  owner data, private maturity, historical node-provider rewards, Dashboard
  analytics, cache operations, or mutation behavior.
