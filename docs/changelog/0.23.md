## 0.23.0 - 2026-08-01

### Added

- Adds `icq sns swap <id|root-principal>` for one resolved SNS. The live
  adapter attempts exactly `get_lifecycle`, `get_sale_parameters`, and
  `get_derived_state`; it does not call the potentially large `get_state`
  method, enumerate participants, apply swap methods to any other SNS, or
  create a cache. Target resolution first reads the unenriched SNS-W inventory
  and then enriches only the resolved SNS.
- Adds `SnsSwapSource`, `MainnetSnsSwap`, `SnsSwapReport`, native nested swap
  DTOs, `build_sns_swap_report_with_source`, and text rendering to the public
  library surface. Report DTOs and rendering remain available without default
  features; live builders and sources remain host-only.
- Retains a failed component as a typed `SnsSwapQueryGap` while preserving the
  other successful component responses. Setup errors remain typed builder
  failures.
- Adds `icq sns upgrade <id|root-principal>` using the official Governance
  `get_running_sns_version` query and SNS-W `get_next_sns_version` query. It
  preserves all six native role hashes, Governance pending-upgrade state, and
  an optional typed next-version gap without reading the upgrade journal or
  downloading Wasms.
- Adds `SnsUpgradeSource`, `MainnetSnsUpgrade`, `SnsUpgradeReport`,
  `SnsVersion`, `SnsPendingUpgrade`, live/custom-source builders, and text
  rendering. Report DTOs and rendering remain available without default
  features; source adapters and builders remain host-only.

```bash
icq sns swap 1
icq sns swap 23ten-uaaaa-aaaaq-aabia-cai --json
icq sns upgrade 1
icq sns upgrade 23ten-uaaaa-aaaaq-aabia-cai --json
```

### Evidence And Bounds

- Validates that custom source evidence identifies the resolved swap canister,
  uses the exact native methods, contains at most one non-empty gap per
  component, and cannot claim a point-in-time guarantee across the three
  queries.
- Preserves raw optional lifecycle codes and native labels, including unknown
  numeric discriminants, sale parameters, participant aggregates, legacy
  Community Fund fields, and the derived SNS-token-per-ICP value.
- Records a fixed three-query swap-component attempt count and successful/gap
  counts. A direct swap report makes five canister queries in total: one SNS-W
  inventory query, one Governance metadata query for the resolved SNS, and the
  three swap queries. The sequential responses are live-only and explicitly
  not atomic.
- Makes SNS discovery fan-out explicit: direct id/Root lookup requests metadata
  for exactly one resolved SNS, unknown lookup requests none, and only the
  complete-inventory `sns list` flow requests metadata for every SNS-W row.
  Metadata results must provide canonical, unique, exact target coverage before
  joining.
- The upgrade report performs two report-specific queries and at most four
  live calls including targeted discovery. Governance running-version failure
  or a missing deployed version fails the report; SNS-W next-version failure
  is retained as a typed gap. A successful `next_version: null` instead means
  that SNS-W returned no blessed successor. Sequential Governance and SNS-W
  responses explicitly carry no point-in-time guarantee.
- Validates exact target principals and native methods, lowercase even-length
  hashes for all six roles, mutually exclusive next-version values and gaps,
  and non-empty trimmed gap reasons. The adapter does not read the upgrade
  journal, download Wasms, fan out to other SNS instances, or create a cache.
- Tightens exact-target metadata evidence so optional payload/error text must
  be non-empty and trimmed, and a metadata error cannot coexist with payload
  fields. Renames swap report counters to the unambiguous
  `component_query_count`, `successful_component_query_count`, and
  `component_gap_count` fields.

### Breaking Rust API

- Replaces `SnsListSource::fetch_deployed_snses` with
  `SnsDiscoverySource::{fetch_sns_inventory, fetch_sns_metadata}` and replaces
  the public joined `MainnetSnsList` source DTO with `MainnetSnsInventory`,
  `MainnetSnsCanisters`, and `MainnetSnsMetadata`. Custom host sources must
  implement the explicit split contract.
- This is a pre-1.0 hard cut: no trait alias, default-method fallback, joined
  legacy DTO, or parallel discovery flow remains. Report JSON, CLI lookup
  syntax, cache schemas, mutation policy, and existing non-discovery source
  capability methods are unchanged.
