## 0.20.0 - 2026-07-31

### Added

- Adds one bounded official Dashboard Metrics API query:

  ```bash
  icq ic metrics instruction-rate
  icq ic metrics cycle-burn-rate \
    --start 1700000000 --end 1700003600 --step 300
  icq ic metrics ic-node-count --format json
  ```

- Supports the official `instruction-rate`, `message-execution-rate`,
  `cycle-burn-rate`, `block-rate`, `ic-node-count`, `ic-subnet-total`,
  `registered-canisters-count`, `total-ic-energy-consumption-rate-kwh`, and
  `boundary-nodes-count` resources.
- Adds `IcMetricKind`, the shared `IcMetricQuery`, typed request/report/series
  and observation DTOs, `IcMetricSource`, custom-source construction, and text
  rendering under `ic_query::ic`. The existing `LiveIcSource` implements the
  new capability.

### Guarantees

- Makes exactly one REST request for one selected aggregate metric. It does not
  enumerate other metrics, fan out over Subnets, paginate, follow up, or write
  a cache.
- Defaults CLI queries to the preceding hour at a 300-second step. Explicit
  `--start`, `--end`, and `--step` values preserve the exact requested window.
  Builders enforce the official timestamp and step bounds, reject future ends,
  and cap requests at 1,000 observations per returned series before a source
  call.
- Preserves documented raw series names, observation Unix timestamps, and
  value strings. Multi-series node and canister counts are retained
  without lossy aggregation.
- Validates custom-source query/provenance echo, exact documented series,
  canonical series order, timestamp bounds and ordering, requested result
  size, and non-empty raw values before projection.
- Reuses `IcSourceRequest`, `IcDashboardReportProvenance`, `IcHostError`, the
  live HTTP transport, and `LiveIcSource`; no parallel Dashboard adapter,
  provenance DTO, or output path is introduced. The shared invalid-source
  display prefix is generalized from "canister source data" to "source data"
  so metric failures are not mislabeled.
- Records `authority: official_ic_dashboard_api`, `network: ic`,
  `certified: false`, and `point_in_time_guaranteed: false`. Metric evidence
  does not inherit Registry or certified canister authority.

### Compatibility

- Existing Dashboard canister CLI grammar, report JSON, public types, and
  live-request behavior are unchanged. Only the shared invalid-source error's
  display prefix is generalized as described above.
- This release adds no compatibility aliases, fallback readers, mutation
  behavior, cache schema, or hidden network calls.
