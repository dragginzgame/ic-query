# 0.10 Changelog

Detailed release notes for the breaking `0.10.x` release line.

Root summary: [../../CHANGELOG.md](../../CHANGELOG.md)

When a patch introduces any new CLI surface, include a fenced `bash` command
example here and in the root changelog. New CLI surface includes commands,
subcommands, options, option values, and new supported option combinations.
Cleanup-only patches without CLI behavior changes should not include command
examples.

## Unreleased

## 0.10.3 - 2026-07-12

### Fixed

- Makes the public-rustdoc debt counter disable forced Cargo color before
  parsing diagnostics, so hosted and local CI measure the same warning set.
- Covers the hosted-CI color environment in the local release guards.
- Runs the complete CI gate against the release commit before
  `release-push` sends the commit and tag upstream.
- Fully verifies the CLI package against the local same-workspace `ic-query`
  source when the new version is not yet on crates.io, while keeping the
  packaged manifest's registry dependency intact.
- Rejects `release-push` when the current-version tag does not resolve to the
  fully checked `HEAD` commit.

## 0.10.2 - 2026-07-12

### Added

- Adds `make install-dev` as the shared local and hosted CI setup target for
  the pinned `ripgrep`, `cargo-audit`, and `cargo-machete` versions.

  ```bash
  make install-dev
  ```

### Fixed

- Makes the library process-boundary check fail with an actionable setup
  message when its `rg` prerequisite is unavailable.

## 0.10.1 - 2026-07-12

### Changed

- Makes ordinary `ic-query` builders and refresh functions silent and exposes
  structured `QueryProgressEvent` callbacks for paged NNS proposal and SNS
  neuron/proposal refreshes.
- Moves terminal detection, same-line progress rendering, and missing-cache
  stderr notices entirely into `ic-query-cli`.
- Shares the persisted SNS cache identity/header models and their common
  validation between neuron and proposal snapshots.
- Centralizes complete-snapshot and refresh-attempt path discovery through one
  private directory collector.
- Updates downstream dependency examples from `0.9` to `0.10` and marks the
  0.10.0 design and release notes complete.
- Adds CI checks that reject process-output ownership in the library and any
  growth in the explicitly measured public-rustdoc backlog.

## 0.10.0 - 2026-07-12

### Changed

- Makes each NNS and SNS family root the sole public path for its requests,
  reports, rows, source traits, builders, renderers, cache paths, and public
  constants.
- Moves the complete topology public contract to
  `ic_query::nns::topology` so it follows the same shape as the other NNS
  families.
- Names the node-provider endpoint constant
  `DEFAULT_NNS_NODE_PROVIDER_SOURCE_ENDPOINT`.
- Lists ICRC request, report, row, and host-source exports explicitly so new
  internal model items cannot become public accidentally through glob exports.
- States mainnet-only network and SNS owner-filter constraints as current
  supported scope instead of implying planned local or cached-owner support.
- Exercises every public ICRC source-adapter builder with complete fixture
  responses instead of leaving unused trait methods as test placeholders.
- Completes the section-style documentation for older registry and NNS boundary
  types and adds a CI guard for the full type-doc contract.
- Adds pinned `cargo-audit` and `cargo-machete` dependency-health checks to the
  local and hosted CI gates. Known transitive maintenance advisories are an
  explicit baseline; new warnings or vulnerabilities fail the gate.

### Removed

- Removes public access to the redundant NNS and SNS nested `report` modules.
- Removes the generic `DEFAULT_NNS_SOURCE_ENDPOINT` node-provider constant
  name.
- Provides no compatibility re-exports, aliases, deprecated paths, or shims
  for the removed public surfaces.
